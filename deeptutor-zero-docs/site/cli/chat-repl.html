原文連結：https://docs.deeptutor.info/zh-cn/cli/chat-repl/

不少朋友裝好 DeepTutor 之後，只會用 deeptutor run 一條條發命令，跑完就退出，總覺得少了點意思。

其實官方還準備了一個更順手的入口：deeptutor chat。

一條命令就能進入互動式對話環境（REPL），特別適合探索性工作、多輪除錯以及手動驅動 DeepTutor 的場景，裡面內嵌了 15 個斜線命令，11 種能力（capability）隨切隨用，用起來是真的香。

更有意思的是，這個環境裡連設定都能熱切換：工具、知識庫、語言、出題數量，全部當場改當場生效。

下面我們就從啟動方式開始，把這套互動式玩法一次講透。

啟動

# 默认 —— chat capability，无 KB，无额外 tool
deeptutor chat

# 预挂载一个 KB，并预开一个用户可切换的 tool
deeptutor chat --kb physics --tool reason

# 以特定 capability 启动（比如固定用 Deep Solve）
deeptutor chat --capability deep_solve

# 续上一个旧 session
deeptutor chat --session sess_abc123

# 通过 flag 传偏好（和 run 一样）
deeptutor chat --language zh --kb papers --history-ref sess_old_xyz

REPL 長什麼樣

┏━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┓
┃ DeepTutor CLI                                                      ┃
┃ Type a message to chat. Ctrl-C interrupts a running turn. Commands:┃
┃   /quit  /session  /status  /new  /clear                          ┃
┃   /regenerate (alias /retry) — re-run the last user message       ┃
┃   /tool on|off <name>                                             ┃
┃   /cap <name>                                                     ┃
┃   /kb <name>|none                                                 ┃
┃   /history add <id> | /history clear                              ┃
┃   /notebook add <ref> | /notebook clear                           ┃
┃   /show last|<n> — expand a tool result or captured thinking      ┃
┃   /refs  /config show|set|clear                                   ┃
┗━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┛
[dim]session=(new) capability=chat tools=[] kb=[] history=[] notebook_refs=[] language=en config={}[/]
You> _

底部那行灰色狀態列，顯示的就是下一輪迴合（turn）會帶過去的所有東西：會話（session）ID、能力、工具、掛載的知識庫（KB）、歷史引用、筆記本（notebook）引用、語言和設定。

一個典型會話

先看一段真實互動，感受一下節奏：

You> 什么是链式法则？

  ✻ thinking…
**链式法则** 说的是：对一个复合函数 `f(g(x))` 求导时，你需要把……相乘

[dim]session=sess_abc123 turn=turn_xyz789 capability=chat[/]

You> /tool on reason
[dim]session=sess_abc123 capability=chat tools=[reason] kb=[] ...[/]

You> /kb math
[dim]session=sess_abc123 capability=chat tools=[reason] kb=[math] ...[/]

You> 用教材第 3 章的一个例题讲讲

  ✻ thinking…
  ● rag(query=chain rule worked example, kb_name=math)
  │ Example: differentiate sin(x²) using the chain rule...
  └ #1 rag — +3 more lines

  ✻ thinking…
教材第 3 章里的例子：

设 `y = sin(x²)`。令 `u = x²`……

You> /quit
$

所有斜線命令

會話管理

命令 作用
/quit 退出 REPL
/session 列印當前 session id
/status 列印當前整個回合狀態——capability、tool、知識庫、語言、config
/new （或 /clear ） 開一個新 session，清掉當前 id
/regenerate （或 /retry ） 用 capability 預設值重跑最後一條 user 訊息；不會轉發當前 /config 覆蓋

能力切換

命令 作用
/cap 切到另一個 capability

合法名稱：chat、ask_questions、deep_solve、deep_question、deep_research、visualize、math_animator、mastery_path、immersive_reading、course_study、immersive_watching。

命令列別名也認，ask、solve、quiz、research、viz、animate、mastery、reading / read、course、watching / watch。

要注意的是，immersive_reading 在命令列上跑的是沒有閱讀器的那套迴圈：命令列既沒有可捲動的視口，也沒有可操作的選區，所以這個模式請在網頁介面用（見沉浸式閱讀）。

You> /cap deep_solve
[dim]capability=deep_solve ...[/]
You> 求 d/dx [sin(x²)]

工具

/tool on <name>     # 下一轮开启某个 tool
/tool off <name>    # 关掉

當前合法的開關項與網頁介面完全相同：brainstorm、web_search、paper_search、reason、geogebra_analysis，以及配好生成模型後的 imagegen / videogen。

而 rag、code_execution、read_memory、web_fetch、write_note、cron 這類上下文門控工具，不能用 /tool 強開，只會在條件滿足時自動掛載。

知識庫

/kb <name>          # 挂载一个 KB（替换当前挂载）
/kb none            # 卸载

歷史會話引用

告訴模型有哪些歷史會話應該當作上下文，不用複製貼上：

/history add sess_prior_xyz
/history clear

這是搭建跨會話上下文的方式，做「接著上次的研究繼續」這類回合非常合適。

筆記本引用

從你的筆記本裡帶入特定記錄：

/notebook add my-notes:rec_abc123,rec_def456
/notebook clear

設定覆蓋

對後續回合生效的按能力維度的設定：

/config show                       # 打印当前 config
/config set num_questions 5
/config set difficulty=hard
/config set difficulty hard
/config clear                      # 重置为默认值

舉個例子，以 --capability deep_question 啟動：

You> /config set num_questions 8
You> /config set question_types '["short_answer","mcq"]'
You> 出几道关于线性回归的题

檢視工具結果

工具結果會截斷為前 10 行、每行 240 字元；思考過程摺疊成提示。兩者共用 /show 序號：

/show last          # 最后一条 tool 结果或 thinking 块
/show 3             # 本 session 的第 3 个捕获块

兩類合計最多快取 32 條。

/refs

列印下一輪迴合會帶過去的所有內容：

You> /refs
[bold]Current state:[/]
  session     sess_abc123
  capability  chat
  tools       [rag, reason]
  kb          [physics, math]
  history     [sess_old_xyz]
  notebooks   [my-notes:rec_abc123]
  language    en
  config      {"difficulty": "hard", "num_questions": 5}

REPL 裡的串流渲染怎麼工作

每一輪迴合按階段（stage）渲染，你會按順序看到：

標記 含義
▶ 非 chat stage 開始；chat 隱藏 responding
✻ thinking… 推理已捕獲，可用 /show 檢視
● (...) 正在呼叫某個 tool
│ 一行 tool 輸出
└ #N — +M more lines; run /show N to expand tool 結果被截斷
普通文字 渲染後的最終 markdown 回覆

ask_user 會彈卡片；用 answer> 回覆繼續，Ctrl-C 中止。

小撇步

多行輸入

要發多行訊息（程式碼片段、長提示詞），每行末尾加一個反斜線 \ 再按 Enter：

You> Please review this Python code:\
def fib(n):\
    if n < 2: return n\
    return fib(n-1) + fib(n-2)

會話中途切能力

一個會話內可以自由切換能力，DeepTutor 會保留對話上下文。

一種常見打法：

You> /cap deep_research
You> /config set mode=report
You> /config set depth=standard
You> 调研一下 2024–2026 年关于 RAG 的论文
[一个很长的研究 turn]

You> /config clear
You> /cap chat
You> 现在写一个 3 段总结，目标读者是非技术背景的人

You> /cap deep_question
You> /config set num_questions 5
You> 基于这些论文出几道测验题

三個回合共享上下文；切換到不相容的能力結構（schema）前，先清空設定。

匯出會話日誌

會話存在共享的會話資料庫裡，想匯出一份乾淨的 markdown 文字稿：

deeptutor session show sess_abc123 --format json | \
  jq -r '.messages[] | "**" + .role + "**: " + .content + "\n"' > transcript.md

從 REPL 到筆記本

某一輪覺得特別滿意？存進筆記本：

# REPL 里
You> /quit

# 然后在 shell 里把 assistant 最后一条消息抓出来
deeptutor session show sess_abc123 --format json | \
  jq -r '.messages[-1].content' > my-answer.md

deeptutor notebook add-md my-notes my-answer.md --title "Chain rule explanation"
