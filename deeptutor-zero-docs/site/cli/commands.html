把 DeepTutor 裝好之後，你平時打交道最多的，就是它的命令列工具（CLI）：deeptutor。

這一頁就是官方的完整命令參考：15 個子命令、每個引數（flag）的型別和預設值、輸出格式、現成範例，全部一次列全。

這套命令能幹的事情比你想的多：出題、深度解題、做研究報告、管理知識庫、維護三層記憶、建立學習夥伴（Partner）……日常學習自動化的活，基本都能交給它，本機真能跑出一條完整的學習流。

數字先給大家劃個重點：光知識庫 kb 一個命令就帶 13 個子命令；doctor 一條命令做 6 項健檢；記憶分 L1、L2、L3 三層；後端跑在 8001 連接埠、前端跑在 3782 連接埠。

很多人看到這裡，基本就放棄了：這麼多命令，誰記得住啊。

別慌，命令不用背，用到哪查到哪就行。下面按官方文件的順序逐個過一遍，命令和引數名我一個字元都沒動，互動式對話環境（REPL）的用法和智慧代理（Agent）自動化分別見文末連結。

deeptutor run —— 單次能力執行

執行一次能力（capability）回合（turn）然後退出。這是智慧代理和腳本最基礎的「做事」命令。

deeptutor run <capability> "<message>" [options]

內建能力：chat、ask_questions、deep_solve、deep_question、deep_research、visualize、math_animator、mastery_path、immersive_reading、course_study（別名 course）、immersive_watching（別名 watching、watch）。

引數（Flag）

Flag 型別 預設值 作用
--session string (新增) 續上一個已有會話
-t / --tool 可重複 [] 僅使用者 toggle； rag / code_execution 忽略
--kb 可重複 [] 掛載一個知識庫
--notebook-ref <id[:record,...]> 可重複 [] 掛載 notebook 記錄
--history-ref 可重複 [] 引用一個歷史會話
-l / --language string en 回覆語言
--config <key=value> 可重複 [] 單個 capability 的 config 覆蓋
--config-json string —— 以 JSON 形式提供 base config；後續 --config key=value 會覆蓋同名 key
-f / --format string rich 僅精確 json 輸出 NDJSON；其餘走 rich

範例

# 简单 chat turn
deeptutor run chat "用大白话解释量子纠缠"

# Deep Solve，带 reasoning + 针对某个 KB 自动挂载的 RAG
deeptutor run deep_solve "求 d/dx [sin(x²)]" --tool reason --kb math

# 生成 5 道测验题
deeptutor run deep_question "线性代数的特征向量" \
  --config num_questions=5 --config difficulty=hard

# Deep Research，JSON 流
deeptutor run deep_research "检索增强生成最近有什么新进展？" \
  --tool web_search --kb papers \
  --config mode=report --config depth=standard \
  --format json

# 续上一个 session
deeptutor run chat "接着刚才的继续" --session sess_abc123

輸出 —— --format rich （預設）

Markdown 富文字。Deep Solve 僅 responding，chat 隱藏橫幅：

  ✻ thinking…
  ● rag(query=chain rule, kb_name=math)
  │ Chain rule: d/dx[f(g(x))] = f'(g(x)) · g'(x)
  └ #1 rag — +5 more lines; run /show 1 to expand

  ✻ thinking…

The derivative of sin(x²) is:

**2x · cos(x²)**

[dim]session=sess_abc123 turn=turn_xyz789 capability=deep_solve rounds=2 tools=1[/]

輸出 —— --format json

每行一個 JSON 物件（即 NDJSON，每行一條 JSON 記錄的格式），方便透過管線交給其他工具：

{"type": "stage_start", "stage": "responding"}
{"type": "tool_call", "content": "rag", "metadata": {"args": {"query": "chain rule", "kb_name": "math"}}}
{"type": "tool_result", "content": "Chain rule: ...", "metadata": {"tool": "rag"}}
{"type": "content", "content": "The derivative of sin(x²) is **2x · cos(x²)**", "metadata": {"call_id": "round-2", "trace_kind": "llm_chunk"}}
{"type": "progress", "content": "", "metadata": {"call_id": "round-2", "trace_kind": "call_status", "call_state": "complete", "call_role": "finish"}}
{"type": "stage_end", "stage": "responding"}
{"type": "result", "metadata": {"response": "The derivative of sin(x²) is **2x · cos(x²)**"}}
{"type": "done", "session_id": "sess_abc123", "turn_id": "turn_xyz789", "metadata": {"status": "completed"}}

事件型別：stage_start、stage_end、thinking、observation、content、tool_call、tool_result、progress、sources、result、error、session、session_meta、done、wait_for_input。

deeptutor chat —— 互動式對話環境

進入一個互動式 chat 會話，用 /slash 命令在會話內做設定。

deeptutor chat [options]

flag 和 run 裡塑形回合的那一組一樣：--session、--tool / -t、--capability / -c、--kb、--notebook-ref、--history-ref、--language / -l、--config、--config-json。完整說明見 互動式 REPL。

deeptutor init —— 引導式初始化精靈

deeptutor init                # 完整配置（询问端口 + LLM + embedding + 搜索）
deeptutor init --cli          # 仅 CLI（跳过端口问题）
deeptutor init --home /path   # 使用非默认工作区

完整流程見 Get Started。

deeptutor doctor —— 這個工作區能跑起來嗎？

在你去翻症狀之前，它會先回答一個問題：DeepTutor 在這裡能不能開一輪會話？所有判斷都讀本機設定，因此預設這次執行完全不聯網。

deeptutor doctor                  # 只读本地配置
deeptutor doctor --online         # 额外向 provider 发一个很小的请求
deeptutor doctor --format json    # 同一份报告，机器可读（--format / -f）

一共六項檢查。其中四項始終是必需項：LLM configuration（模型設定）、LLM credentials（模型金鑰）、LLM endpoint（模型 API 位址）和 Runtime storage（資料根目錄可寫）。RAG prerequisites（檢索增強生成的前置條件）是可選項，失敗報 WARN。Provider response 跳過時是可選項；真正執行 --online 探測後就是必需項，失敗報 FAIL 並以退出碼 1 結束。

狀態 含義
PASS 該項通過。
FAIL 必需項失敗——啟動前先修掉。
WARN 可選項失敗；它覆蓋的那個功能不可用。
SKIP 沒什麼可查的（沒有設定知識庫，或沒加 --online ）。

任一必需項失敗時退出碼為 1，所以 deeptutor doctor 可以直接當作容器入口或者持續整合（CI）步驟裡的門禁。--format json 輸出 {"ok", "online", "checks": [{"key", "label", "status", "detail", "required"}]}，讀 ok 就好，不要去解析那張表。

deeptutor start / deeptutor serve

# 同时启动后端 + 前端（阻塞；Ctrl+C 同时停掉）
deeptutor start
deeptutor start --home /path
deeptutor start --dev                   # 前端热更新（HMR），而非生产构建

# 仅后端
deeptutor serve --host 0.0.0.0 --port 8001
deeptutor serve --reload                # 文件变动时热重载（仅开发用）

deeptutor kb —— 知識庫管理

kb list

deeptutor kb list                # Rich 表格
deeptutor kb list --format json    # --format / -f

JSON 輸出：

[
  {
    "name": "physics",
    "status": "ready",
    "documents": 12,
    "rag_provider": "llamaindex",
    "is_default": true
  },
  {
    "name": "math",
    "status": "indexing",
    "documents": 4,
    "rag_provider": "llamaindex",
    "is_default": false
  }
]

kb info 

deeptutor kb info physics

回傳這個知識庫的中繼資料、文件列表、統計資訊和索引狀態。

kb create 

# 单个文档
deeptutor kb create physics --doc chapter1.pdf       # --doc / -d

# 多个文档
deeptutor kb create physics --doc chapter1.pdf --doc chapter2.pdf --doc exercises.docx

# 整个目录
deeptutor kb create textbooks --docs-dir ./my-pdfs

支援文字、PDF、Office 與 EPUB；圖片要求向量化模型（Embedding）和大語言模型（LLM）都支援多模態。

kb add

往已有知識庫裡增量新增文件：

deeptutor kb add physics -d chapter3.pdf
deeptutor kb add physics --docs-dir ./supplements

kb delete 

deeptutor kb delete physics              # 要求确认
deeptutor kb delete physics --force      # 跳过确认（--force / -f）

kb set-default 

deeptutor kb set-default physics

這會標記工作區的預設知識庫。命令列互動環境仍然從「無知識庫」開始，只傳送 --kb 或 /kb 選中的那個。

kb search 

deeptutor kb search physics "什么是角动量？"
deeptutor kb search physics "..." --mode hybrid --format json  # --format / -f

--mode 取決於引擎：LlamaIndex 忽略該引數；LightRAG=naive|local|global|hybrid|mix（預設 hybrid）；GraphRAG=local|global|drift|basic（預設 local）。

kb add-github-source

把儲存庫中的 Markdown 登記為可追蹤來源：

deeptutor kb add-github-source physics --repo owner/repo \
  --branch main --path docs/ --glob '*.md'

--repo / -r 必填；--branch / -b 預設 main，--path / -p 預設儲存庫根目錄，--glob / -g 預設 *.md。

kb remove-github-source 

deeptutor kb remove-github-source physics --source-id <id>

--source-id / -s 指定已登記的來源。

kb add-web-source

登記一次有界的文件站點抓取：

deeptutor kb add-web-source physics --url https://docs.example.com \
  --max-depth 3 --max-pages 200

--url / -u 必填；抓取深度預設 3，頁面預算預設 200。

kb remove-web-source 

deeptutor kb remove-web-source physics --source-id <id>  # --source-id / -s

kb list-sources 

deeptutor kb list-sources physics

列出已登記的 GitHub（程式碼託管平台）與 Web 來源、最近狀態，以及已同步的檔案/頁面數。

kb sync 

deeptutor kb sync physics

立即同步所有已啟用的 GitHub 與 Web 來源，顯示各來源狀態及可用的變更計數。

重新索引

重新索引沒有命令列入口，要從網頁介面（Knowledge → 選知識庫 → Index versions 標籤頁 → Re-index now）觸發。換了向量化模型之後，通常就需要這一步。

deeptutor skill —— 技能庫與 Hub

deeptutor skills 是 deeptutor skill 的頂層別名。DeepTutor 已原生內建 EduHub（其開放技能儲存庫），無需任何設定：裸 slug 或 eduhub: 字首都會解析到它（clawhub: 同樣內建）。

deeptutor skill list                              # 本地技能列表，含 hub 来源信息
deeptutor skill search "苏格拉底" --hub eduhub --limit 10
deeptutor skill install eduhub:socratic-tutor     # 校验 → 下载 → 注册
deeptutor skill install socratic-tutor@1.2.0      # 裸 slug 默认 eduhub；@ 钉住版本
deeptutor skill install clawhub:gh-release-notes  # 其他 hub 通过前缀解析
deeptutor skill remove socratic-tutor

不是 DeepTutor 使用者？EduHub 是一個獨立、相容 ClawHub 的註冊表，任意支援技能的智慧代理（Claude Code、Codex……）都能透過 eduhub 命令列使用：npx eduhub skills install socratic-tutor。

技能儲存庫（hub）的引用格式為 <hub>:<slug>[@version]，也支援帶 owner 的 <hub>:<owner>/<slug>[@version]。

所有安裝都要過同一道匯入門：先查儲存庫的安全裁定（被標記的包，除非顯式傳 --allow-unverified，否則拒裝）、壓縮包帶 zip-slip / zip-bomb 防護解壓、支援檔案過文字/腳本副檔名白名單（二進位檔案永遠進不了工作區）、檔案頭部 frontmatter 中繼資料裡的 always: 會被剝掉，下載來的包不可能把自己注入每條系統提示詞（system prompt）。來源資訊（儲存庫、版本、裁定）記錄在技能旁邊的 .hub-lock.json 裡。

install 的引數：--name 換個本機名字安裝，--force 覆蓋同名技能，--allow-unverified 無視可疑裁定繼續裝。

發布你自己的技能

同一套命令列也是儲存庫的創作端。login 開啟瀏覽器完成授權並把權杖存在本機；publish 上傳一個技能目錄；update 是後續維護的迴圈。

deeptutor skill login --no-browser                 # 只打印授权链接，不自动打开浏览器
deeptutor skill publish ./my-skill --version 1.1.0 --token "$TOKEN" --yes
deeptutor skill update ./my-skill                  # 目录可选；发布或回退
deeptutor skill logout

這四個命令都接受 --hub <name> 指定預設之外的儲存庫。publish 還接受 --slug、--track、--token、--yes / -y；update [directory] 接受 --token，適合不想把登入態存在本機的場合。

額外的註冊表，或者覆蓋某個內建項（例如把 eduhub 指向自建映像檔），在 settings/skill_hubs.json 裡宣告：type: "clawhub" 指向任意相容的 HTTP API，type: "command" 包一個把包下載到 {dest} 的命令列工具，"default" 決定裸 slug 使用哪個儲存庫。

多使用者部署裡，這套主機命令列操作的是管理員工作區：裝好的技能在 grant 分配之前對其他使用者不可見。相比之下，已登入使用者在網頁端點 Install 會寫入呼叫者自己的私有技能庫；管理員分配的技能仍按 grant 限定且只讀。
