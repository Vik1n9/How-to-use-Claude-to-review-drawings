原文連結：https://docs.deeptutor.info/zh-cn/get-started/pypi/

前面幾篇把 Docker 和原始碼安裝都講過了，相信不少朋友也是透過那個方法認識 DeepTutor 的。但如果你只想最快跑起來，今天這篇才是正主：選項 1，從 PyPI（Python 官方包儲存庫）安裝。

這是官方定義裡最順滑的路徑：完整本機 Web 應用 + 命令列工具（CLI），無需 clone（克隆儲存庫）。環境要求就兩行數字：Python 3.11–3.14，以及 PATH 上的 Node.js 20+，deeptutor start 會拉起內建的 Next.js standalone 伺服器。

但是問題來了。裝是簡單，init 精靈要問一堆連接埠和模型設定，第一次接觸容易懵？接下來，我們就從安裝到初始化完整走一遍，整個過程只能用兩個字形容：絕了。

一、安裝

mkdir -p my-deeptutor && cd my-deeptutor
pip install -U deeptutor
deeptutor init     # 提示输入端口 + LLM 提供商 + 可选 embedding/search
deeptutor start    # 同时启动后端 + 前端；保持终端开着

第一行建一個工作目錄並進去；第二行用 pip（Python 套件管理器）把 deeptutor 裝上；第三行跑初始化精靈；第四行同時啟動後端和前端。

deeptutor init 會詢問：

  • 後端連接埠 （預設 8001 ）
  • 前端連接埠 （預設 3782 ）
  • LLM 提供商 / base URL / API key / 模型
  • 可選 embedding 提供商 （用於 RAG / 知識庫）
  • 可選搜尋提供商 （用於 Web Search）

deeptutor start 之後，開啟終端機裡列印的前端地址 —— 預設是 http://127.0.0.1:3782。按 Ctrl+C 同時停掉後端和前端。

跳過 deeptutor init 也行，應用會以預設連接埠和空設定啟動，之後可到 設定 → Models 設定 Connections、LLM、Task Models、Embedding、Search、TTS、STT、文生圖與文生影片。

二、試用預發布版本

普通 pip install -U deeptutor 只會停在穩定版，PyPI 預設跳過預發布版本（如 1.X.0b0 這類 beta），除非顯式選擇：

pip install --pre -U deeptutor
# 或精确锁定某个版本：
pip install -U "deeptutor==<version>"

三、可選 extras

PyPI wheel 本身已包含完整 Web 應用 + CLI。附加能力按可選元件（extras）安裝，例如全部內建 Partner 管道開發工具包（SDK）（WeCom、QQ、Slack、飛書、Telegram、釘釘等）：

pip install -U "deeptutor[partners]"

完整 extras 總表（matrix、matrix-e2e、math-animator、dev、all）見 從原始碼安裝 —— 同樣的 extra 名對 PyPI 包同樣有效。

四、檔案存在哪裡

工作區位於執行命令時所在的目錄（首次啟動會在那裡建立 data/ 目錄）。想覆蓋位置：

DEEPTUTOR_HOME=/opt/deeptutor deeptutor start
# 或：
deeptutor start --home /opt/deeptutor

首次 init 後的目錄結構：

my-deeptutor/
└── data/
    ├── memory/
    └── user/
        ├── settings/
        │   ├── system.json
        │   ├── auth.json
        │   ├── integrations.json
        │   ├── interface.json
        │   ├── model_catalog.json
        │   ├── document_parsing.json
        │   ├── pageindex.json
        │   ├── ima.json
        │   ├── llamaindex.json
        │   ├── graphrag.json
        │   ├── lightrag.json
        │   ├── lightrag_server.json
        │   ├── main.yaml
        │   └── agents.yaml
        └── workspace/

各設定檔案的含義在下面 設定參考 一節。

data/user/settings/ 設定檔案

data/user/settings/ 下的所有檔案都是純 JSON / YAML。瀏覽器裡的 設定 頁是推薦的編輯入口。

檔案 用途
model_catalog.json Connections，以及 LLM、task、embedding、search、TTS、STT、影像與影片服務的 profiles
document_parsing.json 、 pageindex.json 、 ima.json 、 llamaindex.json 、 graphrag.json 、 lightrag.json 、 lightrag_server.json 文件解析與知識庫引擎設定
system.json 後端 / 前端連接埠、對外 API base、CORS、SSL 驗證、附件目錄與上傳/提取上限
auth.json 可選的認證開關、使用者名、密碼雜湊、token / cookie 設定
integrations.json 可選的 PocketBase 與 sidecar 整合設定
interface.json UI 語言與模型輸出語言 / 主題 / 側邊欄偏好
main.yaml 執行環境預設行為與路徑注入
agents.yaml 各 capability / 工具的溫度和 token 設定

專案根目錄的 .env 不會 被當作應用設定載入。建議從瀏覽器裡的 設定 → Models 設定，或直接編輯 model_catalog.json。

五、安裝之後能直接用什麼

不用離開工作區，隨時進 CLI：

deeptutor chat                                          # 交互式 REPL
deeptutor run chat "解释一下傅里叶变换"                   # 单次执行
deeptutor kb create my-kb --doc textbook.pdf            # 建一个知识库
deeptutor memory show                                   # 查看记忆
deeptutor config show                                   # 查看当前配置

進互動式對話環境（REPL）聊天、單次提問、建知識庫、查記憶、看設定，全在終端機裡搞定。完整命令面：DeepTutor CLI。

六、升級

pip install --upgrade deeptutor
deeptutor start

兩行命令原地升級，工作區會在升級中保留。

瀏覽器裡的 設定 → 關於 會識別 PyPI 安裝、檢查最新版本，也可以替你執行同樣的包升級。你可以選擇自動檢查以及是否包含預發布版；更新完成後按頁面提示確認版本並重新啟動應用。

七、常見錯誤

macOS 上 python: command not found

python3 -m pip install -U deeptutor
python3 -m deeptutor init   # 或者，如果 entry point 在 PATH 上，直接 `deeptutor init`

Node.js 不在 PATH 上

deeptutor start 會拉起內建 Next.js 伺服器，需要 PATH 上有 node。從 https://nodejs.org 裝 Node 20+，或 brew install node@22。

連接埠 3782 或 8001 被佔用

lsof -i :3782          # macOS
ss -ltnp | grep :3782  # Linux

殺掉佔用的處理程序，或重跑 deeptutor init 改連接埠。

LLM provider 401 Unauthorized

API key 被服務商拒絕了。在 設定 → Models → LLM 重新輸入，或：

deeptutor init   # 重跑向导，工作区会保留

更多問題：故障排查。
