最近不少朋友在後台問我，港大開源的那個 AI 學習助手 DeepTutor，到底要怎麼裝到自己電腦上。

我自己把四種安裝方式全部跑了一遍，整體感覺就是：門檻比想像中低很多。

先給大家報幾個關鍵數字：Python 只要求 3.11–3.14，裝好之後會在本機起兩個服務，後端 8001 連接埠、前端 3782 連接埠，瀏覽器開啟就能用。

但是問題來了。四種方式到底該選哪一種？環境要求、連接埠設定、預發布版本這些細節，不提前搞清楚很容易踩坑。

接下來，我們就把這 4 條安裝路徑和裝好之後的所有要點，一次給你講明白。

先搞懂一件事：所有方式共用同一套工作區

不管你選哪種安裝方式，DeepTutor 都用同一份工作區佈局。

設定檔案放在你執行命令所在目錄下的 data/user/settings/（或者你顯式指定的 DEEPTUTOR_HOME / deeptutor start --home 位置）。

知識庫、記憶、學習夥伴執行環境、多使用者帳號和稽核日誌，也全都在同一棵 data/ 樹裡。

所以部署的時候，只需要把這棵 data/ 目錄持久化好，其他都不用操心。

完整的網頁應用，推薦流程就一句話：挑一個工作區目錄 → 安裝 → deeptutor init → deeptutor start。

選擇安裝路徑

方式 適用場景 頁面
PyPI 新手、追求最順滑流程、不想 clone PyPI 安裝
原始碼 開發者、需要熱重載 原始碼安裝
Docker 生產部署、託管主機、需要持久化卷 Docker
純 CLI 無介面伺服器、被其他 agent 排程、不需要 Web UI 純 CLI 安裝

簡單點評一下：新手朋友直接走 PyPI（Python 官方包儲存庫）這條線，一條命令的事；要改程式碼、要熱重載的開發者走原始碼；上伺服器、掛託管主機就用 Docker（容器部署工具）；純命令列方案則專門留給無介面伺服器和被其他智慧代理排程的場景。

🧪 想試預發布版本？ 普通 pip install -U deeptutor 只會停在穩定版，PyPI 預設跳過預發布版本。用 pip install --pre -U deeptutor 切換，或精確鎖定版本號：pip install -U "deeptutor==<version>"。

最低環境要求

元件 版本
Python 3.11–3.14
Node.js 20+ （PyPI 安裝） / 22 LTS （原始碼安裝，對齊 CI 與 Docker）
記憶體 取決於所選模型和工作負載
硬碟 取決於安裝 extras 和工作區資料

除了上面這些，你還需要一個大語言模型（LLM）服務商（Provider）。

託管服務通常需要 API 金鑰（API key）；而 Ollama、LM Studio、llama.cpp、vLLM 這些本機服務商，不需要金鑰也能跑，直接白拿本機模型，相當香。

另外，向量化模型（Embedding）服務商是可選的，只有用到知識庫的時候才需要設定。

啟動後會監聽什麼

執行 deeptutor start 之後會起兩個服務：

服務 預設連接埠
FastAPI 後端 8001
Next.js 前端 3782

很多人看到這裡，基本就放棄了：萬一連接埠被佔了怎麼辦？

其實完全不用慌。這兩個連接埠都可以在 data/user/settings/system.json 裡改，或者在 deeptutor init 精靈裡現場指定，靈活得很。

裝好之後

只要你能開啟 http://localhost:3782/，就算部署成功了。

  • 探索 DeepTutor —— Chat、Partners、Co-Writer、Book、Knowledge、Space、Memory、Settings 的總覽
  • DeepTutor CLI —— 在終端機裡驅動核心執行環境與工作區操作
  • Partners 夥伴與管道 —— 把持久化的 AI 導師連到 WeChat、WeCom、QQ、Telegram、Slack、飛書等管道
  • 多使用者部署 —— 部署給一個團隊

如果遇到問題，跳到 故障排查。
