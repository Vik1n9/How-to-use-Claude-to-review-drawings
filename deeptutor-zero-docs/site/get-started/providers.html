最近 DeepTutor 系列寫了好幾篇，後台被問得最多的問題只有一類：模型到底怎麼配？

答案比想像中豪華。DeepTutor 的模型 catalog 一共覆蓋 8 類服務：大語言模型（LLM）、Task Models、向量化模型（Embedding）、搜尋、語音合成、語音識別、文生圖與文生影片。光 LLM 服務商（Provider）就收錄了 36 家，從 OpenAI、Anthropic 到本機 Ollama 全都排在選單裡。

但是問題來了。36 家服務商怎麼選、怎麼填，舊的 LLM_* 環境變數為什麼突然不認了？接下來，我們就把設定面板徹底拆一遍。

先記一個硬規矩：模型憑據和選擇只從 catalog 解析；舊的 LLM_*、EMBEDDING_*、SEARCH_* 環境變數寫法已不能設定它們。專案根目錄的 .env 檔案不會自動載入。

一、設定入口和優先順序

日常設定請用 設定 → Models；它會寫入 data/user/settings/model_catalog.json 並 apply 變更。deeptutor init 只覆蓋首次啟動的 LLM、embedding 與 search 設定。

連線（Connections）。 設定 → Models → Connections 儲存一份 vendor 憑據並關聯到支援的模型服務 profiles；未關聯的服務仍保留自己的憑據。

Task Models。 與 LLM 同形的 task service 負責會話標題和 Home 起始建議，可複用 LLM provider；留空時繼承 LLM。

設定

Embedding profile 的 Base URL 必須是完整 endpoint，不能只填 provider API root：

设置 → Models → Embedding
Provider: OpenAI
Model: text-embedding-3-large
API key: sk-xxx
Base URL: https://api.openai.com/v1/embeddings
Dimension: 3072

警告：建好知識庫之後再換 embedding 模型會引發維度不匹配。DeepTutor 會檢測到並提醒你，換了模型就要把知識庫重建。

設定

设置 → Models → Search
Provider: Brave
API key: your-api-key

web_search 工具預設啟用。沒有設定 search profile 時，它使用無需憑據的 DuckDuckGo；只有想換 provider 時才需新增 profile，也可選擇 none 顯式關閉。舊的 exa、baidu、openrouter 值仍只是棄用的相容選項。

Brave 還有免費額度，配合本機模型能把成本壓到零，免費到底。

五、語音與生成服務商

模型頁面上除了 LLM、嵌入和搜尋之外，還有四項服務。它們的設定方式相同（一個服務商連線加一份模型 id 目錄），各自解鎖一個具體的功能面：

服務 提供商 解鎖什麼
語音合成（TTS） openai 、 azure_openai 、 groq 、 siliconflow 、 openrouter 、 vllm 、 dashscope 、 custom 助手回覆的朗讀。
語音識別（STT） openai 、 azure_openai 、 groq 、 siliconflow 、 openrouter 、 vllm 、 dashscope 、 custom 輸入框上的麥克風。
文生圖 openai 、 azure_openai 、 volcengine 、 siliconflow 、 openrouter 、 dashscope 、 custom 、 custom_chat imagegen 聊天工具。
文生影片 volcengine 、 dashscope 、 custom videogen 聊天工具。

影像與影片生成是工具，不是模式：配好模型之後，用自然語言要一張圖，智慧代理就會呼叫工具，並把結果行內預覽、附上可下載的檔案。影片生成以非同步任務執行，所以這一輪會報告進度，而不是乾等著。

警告：custom_chat 是給那些透過 chat 端點而非專門的 images/generations 端點提供影像生成的服務商用的。如果 profile 型別選錯，key 有效也可能無法出圖。

六、本機模型

可以說，對於經常折騰 AI 的朋友來說，這部分還非常香。DeepTutor 透過若干 provider 支援本機託管的模型。

Docker 裡連線宿主機模型時，localhost 指容器自身；請用 host.docker.internal 或參考 Docker 文件。

Ollama

LLM profile: Ollama | llama3.1 | http://localhost:11434/v1
Embedding profile: Ollama | nomic-embed-text | http://localhost:11434/api/embed | 768
API key: 留空

LM Studio

Provider: LM Studio
Model: your-model-name
Base URL: http://localhost:1234/v1
API key: 留空

vLLM

Provider: vLLM
Model: your-model-name
Base URL: http://localhost:8000/v1
API key: 留空；只有服务端要求时才填写

llama.cpp

Provider: llama.cpp
Model: your-model-name
Base URL: http://localhost:8080/v1
API key: 留空

Lemonade

Provider: Lemonade
Model: your-model-name
Base URL: http://localhost:13305/api/v1
API key: 留空

這五套設定全部照抄就能用，本機模型零 API 金鑰，填上地址就通。
