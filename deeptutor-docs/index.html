最近不少朋友在後台問我：有沒有那種能把學習資料餵進去，還能全天候陪聊答疑的開源 AI 工具？

還真讓我挖到一個。香港大學資料智慧實驗室開源了一個專案，叫 DeepTutor，定位就是個個人化學習助手。

先說幾個能打動人的數字：4 種安裝方式隨便挑，16 個聊天管道隨便接，還自帶三層記憶和知識庫。

但是問題來了。功能這麼多，官方文件足足 50 頁，到底該從哪裡開始看？

別慌，這一頁就是整個文件站的導航中樞，下面我把所有入口都給你擺好，照著路徑走就行。

DeepTutor 是什麼

DeepTutor 是開源、agent-native（智慧代理原生）的個人化學習助手。

它靠一套共享執行環境，把聊天、深層能力、學習夥伴、書籍生成、協同寫作、RAG（檢索增強生成）和三層記憶全部串在一條管線上。

更有意思的是，學習夥伴（Partner）還能把同一套聊天智慧代理迴圈帶進外部聊天管道，並且自帶專屬的靈魂設定、資料庫、工具和工作區。

專案由香港大學資料智慧實驗室建置，Apache 2.0 協定，對想白拿一款學習神器的朋友來說，真的非常香。

幫助與社群

  • Discord —— 提問最快的地方
  • GitHub Discussions —— 長篇問答和設計討論
  • Issue Tracker —— Bug 反饋與功能建議
  • SKILL.md —— 寫給驅動 DeepTutor 的 AI 代理的規範化交接文件

我的建議是：先點上面的「快速上手」裝起來，再按「探索 DeepTutor」把功能過一遍，玩到後面想擴充、想接聊天管道，生態和夥伴那兩篇隨時等你。

實際效果還會受到模型、提示詞以及具體使用場景的影響，建議大家結合自己的需求實際體驗評估。
