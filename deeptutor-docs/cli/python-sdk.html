DeepTutor CLI · Python SDK

20 行程式碼接入 DeepTutor！官方 Python 開發工具包無需起服務，Python 3.11–3.14 直接內嵌 AI 能力！

在非同步 Python 應用中直接嵌入 DeepTutor 的回合、會話、能力與筆記本執行環境。

原文連結：https://docs.deeptutor.info/zh-cn/cli/python-sdk/

不少朋友用 DeepTutor 的姿勢是命令列一把梭，但如果你手上的專案本來就是 Python 寫的，其實還有一條更優雅的路：把整套能力直接嵌進你自己的應用裡。

如果你當初跟我一樣，總覺得調 AI 必須單獨起一個服務、再走一遍 HTTP 請求，那這個方案真的會刷新你的認知。

靠的就是 DeepTutorApp，DeepTutor 穩定的行程內 Python 開發工具包（SDK）。它暴露的回合資料結構與執行環境約定，和命令列工具（CLI）用的是同一套：不用另行啟動命令列行程，也不必透過 HTTP API 發請求。

什麼時候用它？你的應用本來就在 Python 中執行，又需要原生訪問串流事件、會話（session）、能力（capability）中繼資料或筆記本（notebook）的時候，它就是最順手的方案，整個接入過程可以說是爽歪歪。

版本要求也給大家劃好重點：Python 3.11–3.14 可用，範例程式碼 20 來行就能跑通一個完整回合。

前置條件

使用 Python 3.11–3.14，安裝 DeepTutor，並初始化一份與命令列相同的工作區：

pip install deeptutor
deeptutor init --home /path/to/workspace

用 DEEPTUTOR_HOME=/path/to/workspace 執行程式；若不設定該變數，DeepTutor 會使用當前工作目錄。

SDK 與 deeptutor chat、deeptutor run 讀取同一套 data/user/settings/ 服務商與執行環境設定，因此開始回合前要先配好可用模型。

執行一個回合

import asyncio

from deeptutor.app import DeepTutorApp, TurnRequest

async def main() -> None:
    app = DeepTutorApp()
    session, turn = await app.start_turn(
        TurnRequest(
            content="Explain the Fourier transform in one paragraph.",
            capability="chat",
        )
    )

    answer = ""
    async for event in app.stream_turn(turn["id"]):
        if event["type"] == "result":
            answer = (event.get("metadata") or {}).get("response", "")

    print(answer)
    print("session:", session["id"])

asyncio.run(main())

TurnRequest 還可接收會話 ID、啟用的工具、知識庫、語言、能力設定、筆記本/歷史引用、夥伴組引用、附件與技能。

可用操作

範圍 方法
回合生命週期 start_turn() 、 stream_turn() 、 cancel_turn() 、 submit_user_reply() 、 regenerate_last_turn()
會話 list_sessions() 、 get_session() 、 rename_session() 、 delete_session() 、 get_active_turn()
能力 resolve_capability() 、 get_capability_contract() 、 get_capability_contracts() 、 get_capability_availability()
筆記本 list_notebooks() 、 create_notebook() 、 get_notebook() ，以及記錄的新增/更新/刪除/引用方法

回合與會話方法是非同步的；能力發現與筆記本方法是同步的。

SDK、CLI 還是 API？

deeptutor run --format json 會建立同樣的 DeepTutorApp 與 TurnRequest，再把每個 stream_turn() 項序列化成一行 NDJSON。它的無頭模式會為空等候中的 ask_user 自動提交空回覆；SDK 呼叫方則自行決定何時呼叫 submit_user_reply()。

怎麼選？透過 shell 管線與智慧代理交接，選命令列工具；行程內非同步整合，選 Python SDK；如果 DeepTutor 需要作為獨立服務執行，或者使用者端不是 Python，則選 HTTP / WebSocket API。

另見

  • 代理交接 —— 以 NDJSON 消費同一條事件流
  • 伺服器端 API —— 跨行程或網路連線
  • 命令參考 —— 設定並檢查共享工作區

實際效果還會受到模型、提示詞以及具體使用場景的影響，建議大家結合自己的需求實際體驗評估。
