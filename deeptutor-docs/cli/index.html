說實話，第一次翻 DeepTutor 的命令列工具（CLI）文件時，我是有點意外的。

一個學習類的開源專案，居然把整套核心執行環境都搬進了終端機，deeptutor --help 裡列出來足足 17 個頂層命令，知識庫、會話、筆記本、三層記憶全都能在命令列裡直接管。

更有意思的是，你還可以把 DeepTutor 交給 Claude Code、Codex、OpenCode、Hermes 這些 AI 智慧代理來驅動，人家讀完一份 skill 文件就能自驅做事，等於白拿一個 24 小時線上的學習助理。

但是問題來了。17 個命令怎麼記？互動式和單次執行兩種用法到底怎麼選？狀態又存在哪裡？

接下來就照著官方文件，把命令地圖、兩種用法和那些關鍵細節走一遍。

DeepTutor 是圍繞 CLI 設計的

DeepTutor 是圍繞 agent-native CLI 設計的：核心執行環境在終端機裡都有對應入口，單輪執行（turn）可以串流輸出 JSON 給程式消費，自動化入口集中到一份 skill 文件裡，AI 代理讀完就能自驅。

部分瀏覽器優先的工作流（比如 Co-Writer 富文字編輯、Memory Workbench）仍然在網頁介面或 HTTP API 裡。

本章節包括：

  • 命令參考 —— 每個頂層命令和子命令的 flag、schema、範例
  • 互動式 REPL —— 在長會話裡用 /slash 命令操作
  • 代理交接 —— 讓 Claude Code / Codex / OpenCode / Hermes 來驅動 deeptutor
  • 伺服器端 API —— deeptutor serve 暴露的 HTTP / WebSocket 表面

快速一覽

# 装包（从 Get Started 选一种路径）
pip install deeptutor

# 配置
deeptutor init

# 交互式 chat
deeptutor chat

# 单次执行，agent 风格
deeptutor run deep_solve "求 sin(x²) 的导数" --tool reason --format json

# 管理知识库
deeptutor kb create physics --doc chapter1.pdf
deeptutor kb search physics "什么是角动量？"

# 运行一个 Partner
deeptutor partner create my-bot --soul "Socratic 数学导师"

# 看三层记忆
deeptutor memory show L3

為什麼是 CLI 優先

終端機體驗 和 AI 代理拿到的體驗是同一份。你在 deeptutor chat 裡寫一條輪次，背後的 TurnRequest schema 和你把 SKILL.md 丟給 Claude Code / Codex 後他們發出的請求是一模一樣的。

  • 核心學習流程都可以在終端機裡驅動；瀏覽器獨佔的編輯和管理面板透過網頁介面 / API 暴露狀態
  • deeptutor run --format json 每行一個 JSON 事件；資料檢查類命令 kb list 、 kb search 、 session show 、 notebook show 等也都能輸出 JSON
  • 會話跨輪次持久化 —— 你可以在網頁、互動式對話環境、單次 run 之間切換並續上之前的上下文
  • 自動化進入點（turns / KB / session / notebook / memory / Partners / config / plugin / provider / book）都在命令列上

兩種使用方式

方式 1 —— 互動式

適合探索性的、多輪的工作：

$ deeptutor chat --kb physics

┃ DeepTutor CLI                                                  ┃
┃ Type a message. /quit /tool /cap /kb /history /show /refs     ┃
┗━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┛
You> 用一个具体例子讲一下链式法则

完整說明：互動式 REPL。

方式 2 —— 智慧代理風格單次執行

適合自動化、持續整合（CI）以及各類 AI 代理執行框架：

deeptutor run deep_solve "求 [[4,1],[2,3]] 的特征值" \
  --tool reason \
  --format json | jq -r 'select(.type == "result") | .metadata.response // empty'

每行 JSON 是一個事件：stage_start、content、tool_call、tool_result、thinking、done。可以管線交給下游智慧代理，或者用 jq 提取最終答案。

完整說明：代理交接。

狀態存在哪裡

所有命令列命令操作的是 和網頁介面同一個工作區。預設情況下，執行環境資料存在你啟動 DeepTutor 時所在目錄下的 data/ 裡。可以用 DEEPTUTOR_HOME=/path、deeptutor init --home /path 或 deeptutor start --home /path 覆蓋。

也就是說，網頁裡聊到一半，終端機裡可以無縫接著來，資料完全是一份，這套打通做得很到位。

--help 永遠在一個 flag 之外

每個命令都支援 --help：

每個子命令也一樣：

$ deeptutor run --help
$ deeptutor kb create --help
$ deeptutor partner start --help

實際效果還會受到模型、提示詞以及具體使用場景的影響，建議大家結合自己的需求實際體驗評估。
