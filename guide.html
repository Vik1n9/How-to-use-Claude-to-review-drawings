消防製圖人員的 Codex GUI 輔助審圖工作流手冊

重要聲明

本手冊中的 AI 工具只能作為輔助初審工具，最終判斷仍需由具備資格與責任的消防設備師或相關專業人員確認。Codex 可以協助整理圖面、建立索引、讀取可見資訊、產出草稿與日誌，但法規條文、距離計算、設備配置意見，都必須回到原圖、正式法規與專業判斷進行人工複核。本手冊所稱「審圖」是指「AI 輔助初步檢查」，不等同於正式審查、簽證或任何法定審核程序。

使用原則新手不要先學一堆指令。先學會把案件資料整理好、用 Codex App 打開正確資料夾、看懂它改了什麼、留下日誌與版本，才是能長期使用的工作流。

1. 工具準備安裝 Codex Windows App，登入 OpenAI / ChatGPT 帳號提供 GUI 對話、檔案預覽、差異審閱與 Git 功能可開啟本機案件資料夾
2. 案件開案用檔案總管建立總資料夾與單案資料夾檢查資料夾是否完整、補齊模板檔案件說明.md、AGENTS.md、案件進度.md

4. 輔助初審提供圖面、確認圖層、查證法規、決定正式意見建立索引、分析可見圖面、整理疑點、輸出草稿AI 輔助審查意見草稿

第一章：認識 Codex GUI 工作方式

Codex 是 OpenAI 的 AI 工作代理。對新手來說，建議優先使用 Windows App：它可以用圖形介面開啟專案資料夾、在同一個視窗裡和 Codex 對話、檢查它產生或修改的檔案，並透過內建 Git 功能留下版本紀錄。

Step 1：安裝 Codex Windows App

操作方式盡量用圖形介面完成：

  • 1. 打開瀏覽器，前往 OpenAI Codex 官方頁面或 Microsoft Store 的 Codex App 頁面。
  • 2. 點擊 Windows 版本下載或安裝按鈕。
  • 3. 安裝完成後，從 Windows 開始功能表搜尋「Codex」並開啟。
  • 4. 依畫面提示登入你的 OpenAI / ChatGPT 帳號。

確認成功：畫面出現 Codex App 主視窗，可以新增或開啟專案，並看到對話輸入區。

Step 2：先理解 Codex 不是正式審查者

Codex 擅長

整理大量檔案、建立索引、比對文字、產生表格、協助寫日誌與草稿。

你必須決定

圖面版本是否正確、設備圖例是否對應、法規條文是否適用、正式缺失是否成立。

禁止交給 AI 決定

正式審查結論、簽證責任、法律效果、未查證的條號與無圖面依據的推定。

Step 3：用 Codex App 開啟資料夾

每次工作都要讓 Codex 站在正確的案件資料夾裡。不要把整個 C 槽或雜亂的下載資料夾交給 Codex。

  • 1. 在 Codex App 首頁選擇「Add project」、「Open folder」或類似的開啟資料夾按鈕。
  • 2. 選擇本案資料夾，例如 C:\消防審圖案件\2026-0615_忠孝案_辦公室。
  • 3. 新開一個 Local thread。新手先使用 Local，不要一開始就使用多個背景工作。
  • 4. 保持預設沙盒與審核權限；若 Codex 要修改或執行動作，先看清楚它要做什麼再核准。
開啟資料夾→輸入 Prompt→審閱變更→人工確認→輸出報告／日誌

第二章：建立案件資料管理架構

審圖工作流最重要的不是第一句 Prompt，而是資料夾。資料夾整理得好，Codex 才知道哪裡是圖面、哪裡是法規、哪裡放報告、哪裡記錄進度。

Step 4：建立總資料夾

用 Windows 檔案總管建立固定位置：

所有案件都放在這個總資料夾底下。不要把案件散在桌面、下載、Line 暫存或不同硬碟裡。

Step 5：建立單案資料夾命名規則

每個案件用同一種命名格式，日後搜尋與排序會清楚很多。

Step 6：建立每案固定結構

C:\消防審圖案件

總資料夾。只放審圖案件，不放雜項下載。

2026-0615_案件名稱_場所用途

單案資料夾。Codex 每次只開啟這一層。

固定子資料夾

輸入、參考、暫存、輸出、日誌各有位置，避免報告與原圖混在一起。

項目放什麼注意事項
01_圖面輸入PDF、DXF、DWG 轉檔、PNG/JPG 截圖、局部放大圖保留原始檔名，若有版次請不要刪掉版次資訊
02_法規參考本案適用法規、內部審圖規則、常見缺失清單只放你願意讓 Codex 參考的資料；過期法規要標註
03_AI分析暫存Codex 產出的中間表格、座標整理、轉檔結果、臨時分析暫存不等於正式成果，交付前要重新確認
04_審查報告輸出AI 輔助審查意見草稿、人工修正版、最終附件草稿檔名要清楚標示「AI輔助」與日期
05_工作日誌每日工作紀錄、人工決策、待確認事項、會議或電話補充每天一檔，日後回查最快

Step 7：建立案件說明

用記事本新增 案件說明.md，這是 Codex 理解本案背景的第一份文件。

第三章：建立 Codex 工作設定

Codex 會讀取專案資料夾中的 AGENTS.md，把它當成這個案件的工作規則。你可以把它想成「交代給 Codex 的審圖工作守則」。

Step 8：建立 AGENTS.md

用記事本新增 AGENTS.md，存到單案資料夾最上層。注意副檔名是 .md，不是 .txt。

Step 9：確認 Codex 讀到設定

在 Codex App 開啟本案資料夾後，貼上這段提示詞。這一步只確認環境，不做審圖。

為什麼這樣問：先確認 Codex 站在正確資料夾，也確認它理解「不確定就需確認」「每次要更新日誌」「不得直接下正式結論」這些底線。

第四章：建立版本與日誌習慣

審圖不是一次問完就結束。你需要知道每一天做了什麼、AI 改了什麼、人工確認了什麼、下一步卡在哪裡。這一章建立兩個習慣：本機 Git 版本存檔，以及工作日誌。

Step 10：建立案件進度總覽

在單案資料夾建立 案件進度.md，它是整個案件的狀態總表。

Step 11：建立每日工作日誌

每日誌放在 05_工作日誌，檔名用日期開頭。Codex 每次完成一段工作後都要更新。

Step 12：用 Codex 建立本機 Git 版本

Git 是版本存檔系統。你不需要一開始就學會指令，只要先建立習慣：每完成一個階段，就請 Codex 幫你建立一個本機版本，並在 Codex 的 review pane 檢查有哪些變更。

為什麼這樣問：你不需要直接打指令，但要要求 Codex 先檢查、摘要、再建立版本。這樣每次存檔前你都知道它準備保存哪些變更。

01

開案版本

建立資料夾、案件說明、AGENTS.md、案件進度與第一篇日誌。

02

索引版本

完成檔案索引與缺資料清單，日誌記錄輸入檔案。

03

分析版本

完成 PDF / 圖片 / DXF 初步分析，人工確認圖層與單位。

04

報告版本

輸出審查意見草稿，日誌記錄待人工複核事項。

第五章：審圖實戰工作流

這一章的 Prompt 可以直接貼到 Codex App。每段 Prompt 都要求 Codex 更新案件進度與每日誌，讓案件不只產出報告，也留下可追溯紀錄。

Step 13：建立檔案索引

目的：先確認有哪些資料，不要讓 AI 還沒弄清楚圖面版本、格式、單位就開始判斷。

Step 14：PDF / 圖片初審

目的：PDF 與截圖適合建立空間理解，但不一定適合精準量測。先看懂圖面，再決定要補哪些局部圖或 DXF 分析。

Step 15：DXF 圖層與座標分析

人工守門點圖層與圖塊對應一定要由人確認。Codex 可以推測「SP 可能是撒水頭」，但不能把推測直接當成正式設備辨識。

目的：先讓 Codex 把可能的圖層與圖塊列出來，再由消防專業人員確認。這一步可以避免後面用錯圖塊做距離計算。

Step 16：人工確認後再計算

目的：這段 Prompt 把「人工確認」放在最前面，避免 AI 自己認定設備圖塊。計算結果仍要抽樣手算或用熟悉的 CAD 工具交叉確認。

Step 17：法規對照

目的：Codex 只能對照你提供的資料。正式條文仍要由人回到官方法規、主管機關解釋或內部審查標準確認。

Step 18：輸出審查意見草稿

第六章：人工複核與交付

看懂三種狀態

標籤意思你應該怎麼做
符合Codex 根據可見圖面與參考資料，判斷此項目看起來符合仍需人工複核，確認圖面版本、設備對應與標準都正確
不符合Codex 發現明顯疑點，判斷可能不符合優先查證圖面依據，不要未確認就列為正式缺失
需確認現有資料不足，或 AI 無法可靠判斷列入追蹤清單，補圖、查法規或由專業人員決定

人工複核清單

1確認 Codex 讀取的是正確版本圖面，不是舊版、截圖草稿或錯案資料。
2確認 DXF 單位、比例與座標倍率，必要時抽樣手算一到兩組距離。
3確認設備圖塊辨識正確，尤其是撒水頭、探測器、消防栓、揚聲器與圖例對應。
4逐條查證報告中引用的法規來源、條號與適用條件。
5確認「不符合」都有明確圖面依據，不是 AI 的猜測或過度延伸。
6確認「需確認」全部進入案件進度與日誌，不要在正式交付前遺漏。

第七章：常見問題

問題一：Codex 找不到我的圖面檔案

先確認你在 Codex App 開啟的是單案資料夾，不是總資料夾、桌面或下載資料夾。再用檔案總管確認圖面是否放在 01_圖面輸入。必要時請 Codex 重新列出資料夾結構，不要直接重問審圖問題。

問題二：Codex 沒有照 AGENTS.md 的規則做

請先確認 AGENTS.md 放在單案資料夾最上層，而且不是 AGENTS.md.txt。若剛修改過設定，重新開啟該案件資料夾或新開 thread，並要求 Codex 先摘要它讀到的工作規則。

問題三：PDF 或截圖看不清楚

不要要求 Codex 猜。請把該區域從 CAD 或 PDF 放大截圖，放到 01_圖面輸入，檔名加上樓層與區域，例如 3F_東側撒水頭局部放大.png，再請 Codex 只針對補圖重新檢查。

問題四：DXF 距離計算看起來不對

最常見原因是單位、比例或圖層對應錯誤。先在 案件說明.md 確認單位，再請 Codex 說明它使用的單位、圖層、公式與代入值。人工抽樣用 CAD 或手算比對，確認倍率正確後再繼續。

問題五：Codex 要修改或建立很多檔案，我該怎麼辦？

不要盲目核准。先要求 Codex 說明它準備修改哪些檔案、為什麼要修改、修改後會產生什麼。使用 review pane 檢查變更；只接受和本次工作相關的檔案。若不確定，請它先不要修改，只輸出計畫。

問題六：我需要學會所有 Git 指令嗎？

不需要。新手先學會三件事：請 Codex 建立版本、看懂變更摘要、在重要階段存檔。指令可以當作背景知識，真正操作由 Codex App 與 review pane 協助完成。

審圖工作流程總結

每次開始新案件，可以直接照這份清單執行。這份總結刻意寫成操作順序，不需要重新閱讀整份教學也能使用。

最後提醒可重複的工作流比一次漂亮的 AI 回答更重要。每個案件都用同一套資料夾、同一份 AGENTS.md、同一個日誌規則、同一個版本節奏，日後才查得到進度、判斷依據與人工決策。
Codex 輔助初審結果僅供內部檢查與討論，正式判斷仍需人工複核。本手冊適用對象為消防設備製圖與審圖相關人員。
