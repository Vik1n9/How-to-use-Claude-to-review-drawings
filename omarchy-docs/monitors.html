螢幕設定

Omarchy 預設假設你用的是 2x 等級的視網膜級顯示器，這是漂亮銳利的程式字型所需要的。幾乎所有搭載高解析度螢幕的新款高階筆電都是為此最佳化的。27 吋 5K（Apple Studio Display、ProArt PA27JCV、Samsung S9、Kuycon G27P）或 32 吋 6K（Apple XDR、ProArt PA32QCV、Kuycon G32P）跑這個設定最對味。

但如果你的顯示器 PPI 未達 218，就要改螢幕設定。比方說 27 吋或 32 吋 4K，可以打開 ~/.config/hypr/monitors.lua（經由 Omarchy 選單的 Setup > Monitors），切換到該組合的建議值：

local omarchy_gdk_scale = 2 local omarchy_monitor_scale = 1.6

如果是 1080p 或 1440p 顯示器，大概直接用 1x 縮放即可：

local omarchy_gdk_scale = 1 local omarchy_monitor_scale = 1

GDK_SCALE 的變更只對變更後啟動的程式生效（而且 GTK 只認整數，請取跟你的螢幕縮放最接近的整數）。所以改完後請關掉已經變得太大的視窗（或用 Ctrl + Alt + Del! 關掉全部視窗）。

你也可以用 Super + / 調高、用 Super + Alt + / 調低，快速走過主要的螢幕縮放比（1x、1.25x、1.6x、2x、3x、4x）。預設設定下，這些變更重開機後依然保留。

把文字調大或調小

螢幕縮放動的是所有東西的大小。如果只想調文字大小，有一個單獨的開關：

omarchy display text size 14

它接受 9 到 20 之間的像素值，會連動 Omarchy 殼層、GTK 程式與你的終端機，讓整個桌面維持比例。不給參數執行會顯示目前值，omarchy display text size reset 回到預設。Foot 是唯一的例外：它無法重載設定，所以執行中的終端機要開新視窗才會套用新大小。

筆電外接螢幕的延伸與鏡像

筆電接上外接螢幕時，預設會自動延伸桌面。但你可以用 Omarchy 選單的 Trigger > Hardware 或 Super + Ctrl + Alt + Delete 切成鏡像。外接的是投影機、你想邊操作邊展示時特別好用。

延伸模式下，闔上筆電上蓋會自動關掉內建螢幕，掀開就自動打開。你也可以用 Omarchy 選單的 Trigger > Hardware 或 Super + Ctrl + Delete 手動控制。

排列多螢幕

Hyprland 支援多螢幕，版面怎麼排可以去看 Hyprland 螢幕說明文件。你也可以把特定工作區綁到特定螢幕。在 Omarchy，這些規則寫在 ~/.config/hypr/monitors.lua，以 hl.monitor 項目表示，檔案裡附了把特定螢幕釘到解析度、位置與旋轉的註解範例。

想要圖形輔助定位多螢幕，也可以試試 Hyprmon 這個 TUI 工具。

控制亮度

螢幕亮度用專屬的亮度增減功能鍵控制。按住 shift 再按，會直接跳到最亮或最暗。按鍵控制的是你正在聚焦的那台顯示器，所以支援 DDC/CI 的外接螢幕跟筆電螢幕一樣都能調。

Apple 顯示器

用 Apple 顯示器時，只要聚焦在那台螢幕上，鍵盤的亮度鍵會自動生效，這是透過 asdcontrol 指令做到的。

注意，用 Apple 6K XDR 時，hyprctl monitors 列表裡可能出現一台幽靈螢幕。可以用類似 hl.monitor({ output = "DP-2", disabled = true }) 的寫法，經由 Setup > Monitors 把它關掉。

Intel 機器請用一般 Thunderbolt 線連接 Apple 顯示器。沒有 Thunderbolt 的機器，通常要用 DP + USB-A 轉 USB-C 的線材才會通。
