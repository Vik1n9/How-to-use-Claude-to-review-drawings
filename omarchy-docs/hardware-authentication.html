硬體驗證

硬體驗證（Hardware authentication）

指紋驗證

許多筆電都配有指紋感應器做驗證。在 Omarchy 中，經由 Omarchy 選單（Super ＋ Space）的 Setup > Security > Fingerprint 即可使用。

它會安裝指紋套件、採集你的指紋、驗證，然後你就能用指紋做三件事：從鎖定畫面解鎖（以 Super ＋ Ctrl ＋ L 觸發鎖定）、進入 sudo 模式、授權系統提示。

筆電上蓋闔上時，指紋提示會自動跳過，直接進入密碼提示，不會讓你對著搆不到的感應器空等。若你外接了沒有感應器的鍵盤，在 sudo 要求指紋時按 CTRL ＋ C 即可改輸密碼。

以 Omarchy 選單的 Remove > Security > Fingerprint 可移除指紋驗證。

Fido2 驗證

若你使用 Fido2 裝置，可經由 Omarchy 選單（Super ＋ Space）的 Setup > Security > Fido2 設定 sudo 驗證。它涵蓋 sudo 與系統授權提示，但不包含電腦解鎖。

以 Omarchy 選單的 Remove > Security > Fido2 可移除 fido2 驗證。
