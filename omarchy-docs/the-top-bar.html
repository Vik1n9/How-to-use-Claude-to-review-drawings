頂列

螢幕頂端那條就是 Omarchy bar。它不是外掛的狀態列，而是 Omarchy shell 的一部分；Omarchy shell 是單一常駐的 Quickshell 行程，選單、通知、OSD 彈窗與鎖定畫面都由它繪製。所以它和一切主題完美搭配，面板一點即開，不必再生一個應用。

它也是桌面上永遠在場的唯一一塊，值得認識那些小圖示在幹嘛。

預設有什麼

頂列分三區：左邊是 Omarchy logo（選單啟動器）與工作區指示器；中央是狀態指示器、時鐘、鍵盤配置、天氣與 Omarchy 更新徽章；右邊是系統匣、agents、藍牙、網路、音訊、顯示與電源。

其中幾個有事才現身：鍵盤配置只在你設了超過一種配置時出現；更新徽章只在有 Omarchy 更新等著時出現；agents 圖示在 Omarchy 首次在機器上發現 AI 程式使用時出現（見 AI）。

點來點去

幾乎每個小工具的左鍵、右鍵與中鍵都有事做，幾個還吃滾輪。大家最常錯過的就是這點：右鍵與中鍵藏了好東西。

小工具左鍵右鍵中鍵 / 滾輪

Workspaces聚焦該工作區無無

Weather預報彈窗整份天氣發成通知中鍵：重新整理

上表並非全都開箱即有：媒體小工具（MPRIS 現正播放，捲動曲名與藝人）與麥克風小工具內建但預設關閉，想要就按下述方式加回來。

面板

點頂列圖示開啟的是面板，是有滑桿、清單與鍵盤導覽的正經彈窗，不是工具提示。每個面板也都有快捷鍵，16 像素的小圖示不必用瞄的：

快捷鍵面板
Super + Ctrl + AAudio
Super + Ctrl + WNetwork
Super + Ctrl + BBluetooth
Super + Ctrl + DDisplay
Super + Ctrl + PPower
Super + Ctrl + Alt + DCalendar
Super + Ctrl + 1-9按右區順序切換第 n 個面板

面板不是唯讀的，它們是辦事的地方：Audio 有主音量滑桿、輸出裝置選擇與逐應用混音，可單獨轉小某個瀏覽器分頁而不動其他；Network 掃 Wi-Fi、顯示訊號強度、連線，還能選 DNS 供應商；Bluetooth 列出裝置並連線斷線，顯示電量；Power 顯示電池狀態、切換電源設定（電池與插電分開記憶），並印一些系統資訊；Display 有亮度滑桿、文字大小、螢幕縮放預設，多螢幕時還有逐螢幕控制， deeper 見 monitors；Clock 開月曆格，附 ISO 週數與月份步進。

每個面板都吃鍵盤也吃滑鼠：方向鍵移動，Return 啟用，Tab 跳到隔壁面板，Escape 關閉。

Super + Ctrl + 1-9 按右區由左往右數面板，tray 沒有面板所以跳過，數字與你手指的圖示對得上。

Tailscale 與 Dropbox

另外兩個小工具在你從 Install > Service 裝了對應服務後才會出現在頂列，值得認識，因為它們不只回報狀態。

Tailscale 面板可連線斷線 tailnet、切換帳號與選出口節點（自己的機器與 Mullvad 區域都會列在清單）。它還能瀏覽你的機器：選定一台後按 s 經 Taildrop 傳檔給它，這是把檔案搬到手機或另一台筆電最快的方式；c 複製機器 IP，n 複製名稱，d 複製完整 DNS 名。每台機器列上也有傳送鈕，愛點就點。終端機同等功能是 omarchy tailscale send <machine> [file...]。

Dropbox 面板處理登入、顯示已用儲存空間，並列出最近同步的檔案。

移除任一服務，該小工具就從頂列下架。

指示器

中央那小簇是指示器小工具，是你開了的模式的狀態圖示：勿擾、夜燈、待辦提醒、錄影中、保持清醒與聽寫。模式啟用時亮起，平時讓路，把滑鼠懸在頂列中央可偷看未啟用的。點指示器就切換該模式。

想讓它們永遠可見，把該小工具的 alwaysShow 設 true。只在乎其中幾個，就在 items 列出來，例如 ["Dnd", "Reminder", "NightLight"]。指示器小工具可以放多個，不同區顯示不同子集也行。

重新排列頂列

頂列自己會動，不必開設定檔搬東西。

抓住頂列中央附近的空白處往別的螢幕邊拖，頂列就搬過去，上下左右都行，每個小工具都會適應（直式頂列退回精簡純圖示）。按住不放也能開始拖。在同一塊空白連點左鍵兩下切換透明。拖任一小工具可換順序或丟到別區。

愛用選單也行，Style > Menu Bar 有位置與透明度。

同樣的事都有指令，dotfiles 派最愛：

omarchy bar position bottom
omarchy bar transparent toggle
omarchy bar move omarchy.clock --section center --index 0
omarchy bar set omarchy.clock format "HH:mm"
omarchy bar defaults          # back to the shipped layout

要整個加入或移除小工具，用 plugin 指令。omarchy plugin list 印出 shell 認得的每個小工具與 id，然後：

omarchy plugin enable omarchy.media --section center
omarchy plugin disable omarchy.weather

隱藏頂列

Super + Shift + Space 把頂列關掉再打開，不殺 shell，面板與快捷鍵照常運作，只是像素還你。選單的 Trigger > Toggle > Menu Bar 也有。

設定檔

全部存在 ~/.config/omarchy/shell.json 的 bar 鍵下，精簡版如下：

{
"version": 1,
"bar": {
"position": "top",
"transparent": false,
"centerAnchor": "omarchy.clock",
"layout": {
"left": [{ "id": "omarchy.menu" }, { "id": "omarchy.workspaces" }],
"center": [{ "id": "omarchy.clock", "format": "HH:mm" }],
"right": [{ "id": "omarchy.audio" }, { "id": "omarchy.power" }]
}
}
}

每個小工具是三個 layout 陣列之一的一筆，設定就寫在該筆上，沒有獨立設定檔，也沒有 config 子物件。時鐘的 format、formatAlt（右鍵循環切換）與 verticalFormat，都直接住在 { "id": "omarchy.clock" } 上。

centerAnchor 指定中央區唯一釘在螢幕正中央的小工具，左右為它讓路，時鐘才能在天氣與更新徽章來去之間永居正中。設空字串則中央清單只當整組置中。

一條值得內化的規則：一旦有了自己的 shell.json，它就是正典。客製前 shell 讀的是 Omarchy 預設檔；你一拖小工具、一跑 omarchy bar 或一手改檔，擁有權就歸你，不再深層合併，未來 Omarchy 新版預設小工具不會自動出現在你的頂列。omarchy bar defaults 隨時把出廠佈局叫回來。

同一檔案頂層、bar 鍵之外，還住著閒置計時：idle.screensaver 與 idle.lock，都是從閒置起算的秒數。預設螢幕保護 150 秒上，鎖定 300 秒上。
