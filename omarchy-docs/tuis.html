文字介面程式

Lazygit

Lazygit 是類似 GitHub Desktop 的替代方案，差別在它跑在終端機裡面。

進入任何受 git 管理的目錄並執行 lazygit 即可直接啟動，也可以在 Neovim 中以 Space G G 啟動。

用 Tab 在不同面板之間切換。在 Files 面板中，用 Space 選取要暫存的檔案，再按 c 建立新的 commit。用 ? 可以查看所有可用指令。

Lazydocker

Lazydocker 與 Lazygit 出於同樣的精神，提供管理容器與映像檔的終端機介面。

以 Super + Shift + D 啟動。

用 s 停止容器，用 r 啟動或重啟。用 ? 查看所有指令。

Btop

Btop 是漂亮的資源管理員，顯示記憶體、CPU、磁碟與網路用量，也列出所有作用中的處理程序並加以管理。

Omarchy 稱它為 Activity，按 Super + Ctrl + T 啟動。它會以浮動視窗開啟，可用 Super + T 將其平鋪。

Herdr

Herdr 是終端機工作區管理員，提供工作區、分頁與窗格，全部跑在可 detach、稍後再接回來的持久連線中。

以 Super + Ctrl + Return 啟動（或接回既有連線）。Omarchy 內建的 Herdr 設定鏡像了它的 Tmux 設定，所以前綴鍵同樣是 Ctrl + Space。以 Super + Ctrl + K 瀏覽全部快捷鍵。

Fastfetch

Fastfetch 顯示系統資訊，例如核心版本、開機時間、主題、CPU、記憶體等。它是熱門的 neofetch 工具的後繼者。

Omarchy 把它包裝成 Omarchy 選單（Super + Space）中的 About。

Disk Usage

當磁碟塞滿卻不知道誰吃掉空間時，從應用程式啟動器（Super + Space）開啟 Disk Usage。它是以互動模式指向整個檔案系統的 dua，可以逐層走進占用空間的目錄，預設由大到小排序，並直接在裡面刪除。

Cliamp

Cliamp 是致敬 Winamp 2.x 的復古終端機音樂播放器，內建 lo-fi 節拍電台。以 Super + Shift + Alt + M 啟動，或從 Omarchy 選單的 Apps 下開啟。按 ? 查看完整快捷鍵列表。

那 Wi-Fi 跟藍牙呢？ What about Wi-Fi and Bluetooth?

Wi-Fi 與藍牙沒有對應的 TUI，這些工作屬於 Omarchy shell。點頂欄的 Wi-Fi 圖示（或按 Super + Ctrl + W）查看網路並連線，點藍牙圖示（或按 Super + Ctrl + B）配對並連接裝置。完整說明請見 networking。

加入自己的 TUI Adding your own

任何終端機程式都能享有完整應用程式待遇。到 Omarchy 選單（Super + Space）的 Install > TUI，給它一個名稱、啟動指令、視窗樣式與圖示，它就會像其他應用程式一樣出現在啟動器中。之後可到 Remove > TUI 將其移除。
