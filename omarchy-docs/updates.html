系統更新

Omarchy 與你的套件都透過 Omarchy 選單（Super + Space）中的 Update > Omarchy 保持最新。

Omarchy 本身是以一般的 pacman 套件形式，安裝自 Omarchy 套件庫（Omarchy Package Repository）。執行更新時，系統會安裝最新的 Omarchy 版本，執行所有待處理的遷移（migration），讓系統與最新版同步，並從 Omarchy Arch 鏡像站與 AUR（如果你有安裝 AUR 套件）更新全部系統套件。

有新版本發布時，時鐘右側會出現一個圓形箭頭圖示，點下去就會開始更新流程。

四個更新通道

Omarchy 沿著四個通道更新：stable（穩定版）、RC（候選版）、edge（前緣版）與 dev（開發版）。新安裝一律從 stable 通道開始，追蹤正式版本，並搭配比最新版落後一個月的穩定版 Omarchy Arch 鏡像站，讓我們先攔下可能需要改設定的不相容問題，才不會波及一般使用者。

如果你願意協助找出這類潛在問題，可以改用 edge 通道。你的 Omarchy 套件會一路追蹤最新開發版，Arch 套件一有新版也能立刻更新。只有熟悉 Linux 且知道如何搶救出問題系統的人，才適合這麼做。

每次重大新版發布前，我們會用 RC 通道做最後驗證。如果你想幫忙做最後打磨，歡迎到 Discord 的 #omarchy-release-candidates 頻道找我們。

最後還有 dev 通道，它把 Omarchy 直接連結到 ~/omarchy 裡的原始碼 git checkout，並搭配 edge 套件。只有直接參與 Omarchy 開發、且能容忍系統損壞的資深 Linux 使用者才該使用。

你可以用 Omarchy 選單的 Update > Channel 切換通道（或在終端機使用 omarchy-channel-set）。

韌體更新

會過期的不只有套件。許多筆電與週邊的 BIOS、SSD 與擴充基座韌體，都透過 Linux 廠商韌體服務（Linux Vendor Firmware Service）發布，Omarchy 選單中的 Update > Firmware 會抓取並安裝你的硬體正在等待的韌體。第一次執行時它會先安裝 fwupd。不少韌體只能在重開機時寫入，所以看到重開機提示不用意外。

不要直接用 pacman／yay 更新

如果你本來就熟悉 Arch，可能會想直接跑 pacman -Syu 或 yay -Syu，但這麼做會錯過 Omarchy 隨新套件一起執行的快照、遷移與設定更新。也正因如此，Omarchy 會攔下直接的系統升級，並指引你改用 omarchy update。（如果你真的知道自己在做什麼，攔截訊息會告訴你如何為單次交易繞過。）

還原有問題的更新

更新後若系統出問題，可以還原到更新前拍攝的快照。只要重新開機，並在開機選單中選擇更新開始之前的那個快照即可。

如果設定檔已經損毀，也可以在終端機執行 omarchy reinstall 重新安裝 Omarchy。這會重裝全部預設的 Omarchy 套件，把你放回 stable 通道並降級太新的套件，同時重置所有設定檔。注意，你對 Omarchy 預設值做的個人設定修改都會被覆寫！
