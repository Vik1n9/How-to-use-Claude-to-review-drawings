人工智慧

Omarchy 把 AI 程式代理人視為一等公民，但不幫你選邊站。相反，每個主流程式代理人命令列介面都預先接好 lazy-loaded 啟動器。啟動器是放在 ~/.local/bin/ 的微型 mise stub，在你首次執行前什麼都不會下載。執行以下任一指令，並在提示時認證：

指令代理人
claudeClaude Code
codexOpenAI Codex
opencodeOpenCode
agyGoogle Antigravity CLI
copilotGitHub Copilot CLI
crushCrush
grokGrok CLI from xAI
piMario Zechner's Pi
ompOh My Pi
oriOri, OpenRouter's harness

ori 是異類：它把其他 harness 接上 OpenRouter 的完整模型目錄，因此 ori claude、ori codex 或 ori opencode 會用你指定的模型啟動那些代理人，ori code 則是 Ori 自己的代理人。

若要以同樣方式包裝其他 CLI，執行 omarchy-mise-install <package> [command-name]。當你執行 omarchy update（或別名 mup）時，這些 stub 會隨 mise 管理的其他項目一起更新。

預設代理人（The default agent）

用 omarchy default agent <name> 或 Omarchy 選單（Super + Space）的 Setup > Defaults > Agent 選擇預設代理人。若該代理人尚未安裝，選擇時會先安裝。全新的 Omarchy 會用一次性通知邀請你做選擇。

選定後，Super + Shift + Ctrl + A 會在專屬終端機視窗啟動預設代理人（若尚未選擇則先彈出選擇器）。也可用 omarchy agent prompt "Review this project" 直接指派任務。這樣啟動的代理人會以各自的免確認、免停手模式在無人值守下執行，要有它們真的會動手的心理準備。且因代理人拒絕記住家目錄的信任狀態，從 $HOME 啟動時會改從 ~/Work 啟動。

終端機也有捷徑：a 在目前終端機內聯啟動預設代理人，c、cx、cy 則直接啟動 OpenCode、Claude Code 與 Codex（同樣是自動核准模式）。佈景主題切換也會同步到代理人：Claude Code、Pi 與 OpenCode 都會跟著 Omarchy 佈景主題走。

代理人面板（The agents panel）

Omarchy 首次在機器上發現 AI 程式用量時，頂欄會長出 agents 圖示（在此之前保持隱身）。背後面板把每個訂閱集中追蹤：方案、5 小時工作階段與每週額度的已用百分比（或預付餘額），以及按日、按模型的 token 用量。Claude Code、Codex 與 Fireworks 開箱即支援。

左鍵點擊頂欄圖示開啟面板，右鍵直接啟動預設代理人。背後的用量紀錄每 15 分鐘由 omarchy agent usage-update 重建，面板甚至可透過同步資料夾合併其他機器的用量，完整設定見 $OMARCHY_PATH/shell/plugins/agents/ 下的 README。

當機診斷（Crash diagnosis）

Omarchy 會監看 systemd-coredump 的行程當機。當程式段錯誤（segfault）時，你會收到「Process crashed」通知——點下去，當機就會連同 Omarchy 的 diagnose-crash 技能一起交給你的預設代理人，代理人會按技能步驟從 core dump 釐清事實，再判斷是否值得往上游回報。也可對 coredumpctl list 中的任意 PID 手動執行 omarchy agent crash <pid>。

監看預設開啟。在 Trigger > Toggle > Crash Capture 下（或 omarchy toggle crash-capture）關閉後通知即停止，但手動的 omarchy agent crash <pid> 照樣可用。

當機也可逐程式靜音，診斷流程結尾會提供此選項。omarchy crash mute hyprland 只停止該程式的通知，omarchy crash mute hyprland off 恢復，單獨執行 omarchy crash mute 則列出已靜音項目。程式路徑與名稱都接受，omarchy crash mute /usr/bin/hyprland 效果相同，名稱含空白請加引號，如 omarchy crash mute 'Some App'。其餘程式照常通知，被靜音的程式照樣會當機——這只是藏起提醒，並不會修好任何東西。

桌面應用（Desktop apps）

Install > AI 選單還收錄兩個圖形 AI 應用：ChatGPT 桌面版，以及與 xAI 模型聊天的 Grok Bot。

本機大型語言模型（Local LLMs）

Omarchy 推薦兩種本機大型語言模型（Large Language Model，簡稱 LLM）方案：LM Studio 與 Ollama。LM Studio 提供圖形介面，可搜尋開放權重模型、安裝並執行，上手最輕鬆。Ollama 則提供命令列介面做同樣的事。若初次接觸本機模型，建議從 LM Studio 開始，兩者都可在 Omarchy 選單的 Install > AI 下安裝。

Omarchy 技能（The Omarchy Skill）

代理人技能（Agent skill）讓 AI 以特定方式使用特定工具，Omarchy 出貨時內建一套調校系統的預設技能，例如改 Hyprland 設定、調頂欄，甚至從零生出新佈景主題。它被符號連結到 Claude Code（~/.claude/skills）、Codex（~/.codex/skills）、Pi（~/.pi/agent/skills）、Antigravity（~/.gemini/config/skills）與通用 ~/.agents/skills 位置，多數 harness 會自動撿到。

但請把此技能視為實驗性質，不同模型用起來效果差異很大。建議先跑 plan mode，看看代理人想改什麼，再決定放行。若代理人把一切搞砸，要有還原變更、甚至執行 omarchy reinstall configs 的心理準備。
