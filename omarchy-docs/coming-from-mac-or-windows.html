從 Mac 或 Windows 過來

如果你在 macOS 或 Windows 上用了好幾年，你的手指記得一百件大腦早已忘記學過的事。這章就是翻譯層：告訴你那些本能在 Omarchy 的去處。各功能本身另有專章詳述，這裡只是地圖。

Super 是全宇宙的中心

你在 Cmd 或 Windows 鍵上練出的肌肉記憶，都轉移到同一個鍵：Super。PC 鍵盤上的 Windows 鍵就是 Super，Omarchy 幾乎所有快捷鍵都以它為錨。

你的 Spotlight、Raycast 或開始選單反射，會變成 Super + Space。它開啟 Omarchy menu，可啟動應用、改設定、裝軟體與截圖，幾乎無所不包，開始打字即可過濾。另有專屬的應用選單 Super + Alt + Space，見 navigation。

沒有 Dock，也沒有桌面圖示

沒有東西可點來啟動，沒有圖示可在桌面排排站。應用從快捷鍵啟動（Super + Return 開終端機，Super + Shift + Return 開瀏覽器，Super + K 列出所有已綁定項目），或從選單啟動。唯一常駐的 UI 是頂列，它接手了選單列、系統匣與通知中心的工作，而且上面幾乎每個小工具的左鍵、右鍵與中鍵都有事做。

視窗自己排好

最大的心態轉換：你不用拖視窗，也不用貼齊螢幕 halves。開一個視窗，它佔滿全螢幕；再開一個，兩者對分。你永遠不必從另一個視窗底下挖出某個視窗，因為視窗互不重疊。

真的需要浮動視窗時，Super + T 可把使用中的視窗切出平鋪（再按一次切回來）。但請先給平鋪一個真正的機會，它是整套系統的心臟，見 navigation。

工作區似曾相識：它們就是 macOS Spaces 或 Windows 虛擬桌面，只是你會真的用，因為 Super + 1/2/3/4 直接跳到某區，Super + Shift + 1/2/3/4 把使用中視窗送過去。沒有動畫延遲，只有即時跳轉。換言之，如果你以前靠多螢幕，現在也許連多螢幕都不需要了。

複製貼上直接能用

Mac 上到處是 Cmd + C，Windows 上到處是 Ctrl + C，唯獨終端機裡 Ctrl + C 會殺掉程式。Omarchy 給你 Super + C、Super + X、Super + V，在所有地方通用，連終端機都一樣，shell 不必另學一套反射。

Windows 來的人：你的 Win + V 剪貼簿歷史在 Super + Ctrl + V，文字與圖片都留，見 unified clipboard & history。

有些事真的不一樣

很多設定住在你要編輯的文字檔裡，而不是點來點去的面板。聽起來很原始，但它意味著每個調整都看得見、能搬到下一台機器，還能進版控。Setup 選單直接把你丟進正確的檔案，改完重啟該重啟的東西。

更新走單一指令 Update > Omarchy，一次更新 Omarchy 本體與系統上所有套件，動手前先做快照。不會有各應用的更新器三不五時煩你，見 updates。

軟體來自套件管理器，不是下載來的安裝程式。

關掉視窗時，應用就真的結束了，沒有 macOS 那種視窗全關程式還在跑的 limbo。Super + W 或 Super + Q（如果你帶著 Q 的指頭記憶來）就是不見。

在 Mac 硬體上

Omarchy 在 Intel Mac 上跑得很好，見 Mac support。鍵盤也很友善：Omarchy 什麼都不重映射，Linux 把 Command 鍵當 Super，所以 Super 就坐在 Cmd 一直以來的位子，你的大拇指不會發現搬家了。

給它兩週

本能轉移得比想像快。把 hotkeys 章速讀一遍，之後忘記綁定就按 Super + K，它會秀出全部。你真正要背的，只有這一個快捷鍵。
