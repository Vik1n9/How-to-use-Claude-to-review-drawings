導覽

Omarchy 裡所有事都走鍵盤，一切！系統剛啟動時，光靠滑鼠你 literally 什麼都做不了。但你可以按 Super + Space 叫出 Omarchy Menu，從這裡幾乎什麼都能做。

但 Omarchy menu 甚至不是平日操作系統的主力方式，我們可以更快！所有最重要的應用都直接綁在各自的快捷鍵上：Super + Return 開終端機，Super + Shift + Return 開瀏覽器。接連按一次，看看 Hyprland 平鋪的魔法：

接著按 Super + J 把它們上下堆疊，而非左右並排。再按一次 Super + J 回到左右並排。然後在瀏覽器上試 Super + Shift + 右方向鍵交換視窗。

再試 Super + Ctrl + T 開活動監控，它會以浮動視窗出現。用 Super + T 把它平鋪（再按一次變回浮動）。再按 Super + Shift + F 開檔案管理員，就得到漂亮的四分割：

用 Super + 方向鍵在想啟用的視窗之間移動，這會切換焦點並把游標移到新應用的中央。

按 Super + Shift + 2 會把目前聚焦的應用搬到第二個工作區，Super + Shift + 1 搬回來。（Super + Shift + Alt + 2 則把應用搬到第二工作區但人不跟過去）。

按住 Super 再用滑鼠點擊視窗，可調整它的位置；按住 Super 再用滑鼠右鍵，可自由縮放視窗。

用 Super + W 或 Super + Q 關閉視窗（Ctrl + Alt + Delete 關掉所有視窗）。

Super + F 全螢幕，Super + Alt + F 全寬（保留頂列），Super + Ctrl + F 視窗內全螢幕（看 YouTube 好用！）。

Dwindle 與捲動佈局

Omarchy 預設佈局叫 dwindle，它讓同工作區的所有視窗永遠可見，必要時把它們縮小也在所不惜。

你也可以把某個工作區切成捲動佈局，視窗左右一字排開，超出螢幕邊緣。用 Super + L 切換單一工作區的佈局。

選擇是按工作區記憶的，會留下來。所以工作區 1 可留 dwindle 瀏覽，工作區 2 用捲動寫程式，重開機回來還是這樣。（Omarchy menu 的 Trigger > Toggle > Workspace Layout 也有同一切換）。

想把捲動佈局當預設，可在 ~/.config/hypr/looknfeel.lua 設定：

hl.config({
general = {
layout = "scrolling",
},
})

群組視窗

視窗可用 Super + G 群組。群組啟用時開的每個視窗都歸入該群組。用 Super + Ctrl + 左/右方向鍵或 Super + Alt + 1/2/3/4 在群組視窗間移動或直達。

Super + Alt + G 把視窗移出群組，再按一次 Super + G 解散整個群組。Super + Alt + 方向鍵則把群組外的視窗搬進群組。

彈出視窗

Super + O 可把視窗從工作區配置中彈出，釘成跟著你跑的浮動視窗，跑到哪個工作區都跟著，適合影片播放器之類。

速查工作區

最後還有一個特殊的速查（scratchpad）工作區，像 Quake 終端一樣蓋在目前工作區上。用 Super + Grave 或 Super + S 切換，用 Super + Shift + Grave 或 Super + Alt + S 把視窗放進去。

它很適合跑 AI 代理的終端機，或想快速操作又不想離開目前工作區的控制項。要把視窗搬出速查，直接送到別的工作區，例如 Super + Shift + 1。

需要一點習慣時間！

像這樣用鍵盤導覽桌面，一開始要適應一下，但一旦習慣，就很難回去傳統滑鼠驅動的桌面了！
