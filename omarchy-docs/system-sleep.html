系統睡眠

系統睡眠（System sleep）：Omarchy 預設啟用暫停（suspend）與休眠（hibernation），但如果你的機器在其中之一上遇到問題，可以將它們關閉。

電源設定檔

筆電上，Omarchy 會分別記住插電與使用電池時的電源設定檔（power profile），並在插拔電源時自動切換。開箱設定即為：插電時效能（performance）模式，吃電池時平衡（balanced）模式。

以 omarchy powerprofiles list 查看機器提供的選項，以 omarchy powerprofiles set autodetect power-saver 設定目前狀態要用的設定檔。若不想插拔任何東西就設定另一種狀態，直接指名：omarchy powerprofiles set battery power-saver。你選的就是下次進入該狀態時會套用的。

切換暫停

在終端機執行 omarchy toggle suspend 即可切換暫停。該指令只是顯示／隱藏 System（或 Super ＋ Esc）選單下的選項，然後你就能觀察它在你的系統上是否穩定運作。若不行，用同一指令再隱藏即可。

切換休眠

在終端機執行 omarchy hibernation setup 即可設定休眠。休眠會在開機碟上建立一個 /swap 子卷（subvolume），大小等同實體記憶體（RAM）配置，因此請確保預留充足空間。在 32GB 的機器上，該卷永遠需要 32GB 以上的空閒空間。休眠同時要求使用預設的 Limine 開機引導程式（bootloader）。

設定完成後，System（或 Super ＋ Esc）下會出現 hibernate 選項，然後你就能觀察它在你的系統上是否穩定運作。若不行，以 omarchy hibernation remove 移除即可。
