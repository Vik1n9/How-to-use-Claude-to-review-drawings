開始使用

Omarchy 使用 ISO 安裝。你可以選擇整顆磁碟安裝（接管整顆磁碟），或剩餘空間安裝（裝進磁碟上未配置的空間），後者就是與 Windows 或其他作業系統雙開機的方式（見 dual-boot install，注意須先在 Windows 關掉 BitLocker）。兩種方式預設都是完整加密，整碟安裝會抹掉所選磁碟，所以若是沿用舊碟，務必先備份！

先下載 Omarchy ISO，寫入 USB 隨身碟（Mac/Windows 用 balenaEtcher，Linux 用 caligula），再從隨身碟開機。

你必須在 BIOS 關掉 Secure Boot 與 TPM。裝 Omarchy 一定要關掉它們，它們是微軟為 Windows 與微軟系 Linux 發行版設計的安全機制。

接著回答設定問題，並像這樣確認：

然後選一顆安裝磁碟，坐下來看安裝秀登場。在最快的新機器上不到一分鐘可裝完，即使舊電腦也不應超過 5 分鐘。

現在你已經可以 Omarchy 了！

請用有線或 2.4GHz 鍵盤！

整碟加密在開機時無法用藍牙鍵盤輸入密碼，就像在 PC 上不能用藍牙鍵盤進 BIOS 一樣。你需要用 2.4GHz 接收器的鍵盤或有線鍵盤（有線延遲也低得多！）。我個人很愛 Lofree Flow84！

幫別人安裝

如果你在幫別人裝機，家人、新員工或買家，就不該替他們回答個人問題。在安裝程式第一個畫面（鍵盤選擇）按 Ctrl + C，Omarchy 會改為替另一位擁有者準備機器。系統會立刻裝好，但鍵盤配置、使用者名稱與密碼等個人設定會延到第一次開機才設定。磁碟預設依然加密，新擁有者在首次開機設的密碼就是加密密碼。（已經用過的機器不重灌也能移交，見 resetting the computer。）

無人值守安裝

把設定放在第二顆磁碟交給 ISO，ISO 就能全自動安裝，不用鍵盤也不用精靈。這是把 Omarchy 當作虛擬機與機群基礎映像的方式，見 unattended installs。

不加密安裝

Omarchy 預設加密安裝。對任何可能遺失或被偷的電腦來說，這是安全負責的選擇，你不會想讓拿到硬體的人讀走資料！

但在特殊情況下，例如受保護電腦的遠端 Omarchy 安裝，或無敏感資料的拋棄式安裝，你可能想不加密安裝。可以在磁碟格式化確認畫面按 Ctrl + C，切換為不安裝加密的版本。

卡住時求助

如果卡住了，通常可以在社群 Discord 的 #omarchy-help 頻道找到願意幫忙的人。
