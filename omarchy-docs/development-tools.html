開發工具

其他編輯器（Alternative Editors）

Omarchy 預設出貨 Neovim，但若想要更主流熟悉的編輯器，可開啟 Omarchy 選單（Super + Space），到 Install > Editor 下查看選項。我們列有 VSCode、Cursor、Zed、Sublime Text、Helix、Vim 與 Emacs。若沒找到想要的，可到 Install > Package 看看 Arch 套件有沒有（若沒有，再到 Install > AUR 查 AUR）。

VSCode、Cursor、VSCodium 與 Helix 提供佈景主題跟隨。

系統全域預設編輯器可在 Setup > Defaults > Editor 下設定。

開發環境（Environment）

Omarchy 可透過 Omarchy 選單（Super + Space）的 Install > Development 區塊架設眾多開發環境。有 Ruby on Rails，也有 JavaScript 三大執行期（Node.js、Bun、Deno），以及 Laravel、Symfony 等熱門 PHP 框架，還有 Go、Rust、Python、Java、Elixir（含 Phoenix）、.NET、OCaml、Zig、Clojure 與 Scala，選擇非常廣。

多數環境由 Mise 管理。它能讓你在同一台機器安裝並執行多個版本的程式語言，像 Ruby 的 rbenv 或 rvm、Python 的 virtualenv，但一套通吃多種環境。

以 Ruby 為例，執行 mise use -g ruby 就會安裝 Ruby 並設為全域預設。若專案根目錄有 .ruby-version 檔，只需在專案根目錄執行 mise i。

Docker

Docker 不需多作介紹，它能執行隔離容器，Omarchy 已裝好完整執行環境，包含 Docker 本體與 Docker Compose。

預設你的使用者不在 docker 群組中。該群組實質等同免密碼 root——其中任何人執行 docker run -v /:/host 就能接管整台機器——因此若直接加入，單一惡意腳本或相依套件以你的身分執行時，一道指令就能拿到 root。所以命令列請用 sudo 執行 Docker（sudo docker ps、sudo docker compose up），而與 daemon 對話的圖形工具——Super + Shift + D 的 Docker TUI 與 Windows VM——會在需要時請求授權。若你理解取捨並想要免 sudo 的便利，可到 Setup > Security > Sudoless Docker 開啟（或執行 omarchy-setup-security-sudoless-docker），系統會在警告後把你加入 docker 群組，之後 docker 與 d 別名都不需 sudo。

別忘了用 Lazydocker 指令，透過 Super + Shift + D 以酷炫的 TUI 管理容器；除非已啟用免 sudo Docker，否則首次會請求授權。

常用本機開發資料庫可用 Omarchy 選單的 Install > Development > Docker DB 在 Docker 中架設。

GitHub CLI

GitHub CLI（GitHub 命令列介面）讓你登入 GitHub 帳號並用它複製私人倉庫。它是 lazy-loading 的 mise stub 之一，首次執行 gh 時會自行安裝。認證請執行 gh auth login，之後可用 gh repo clone org/repo 取回私人倉庫。

它還能執行眾多其他 GitHub 操作，執行 gh 即可查看全部功能。

另有 lazy-installing 的 ghui stub，可在 TUI 中管理 pull request；lazygit 已預裝，若想在 TUI 中操作 git 本體也沒問題。
