點檔設定

Omarchy 主要透過住在 ~/.config 裡的所謂點檔（dotfiles）來設定。那些是你的檔案，改了就是你的。住在 /usr/share/omarchy 的檔案屬於 Omarchy 自己，請不要亂動。如果你需要改 /usr/share/omarchy 裡的東西，正確做法是在 ~/.config 裡覆寫同一個值。

常用設定可以直接從 Omarchy 選單（Super + Space）編輯，例如 Setup > Monitors、Setup > Keybindings、Setup > Input 與 Setup > Config > [file]。這樣編輯的好處是，存檔離開編輯器後，需要重啟的行程會自動重啟（預設編輯器是 Neovim，記得用 :wq 存檔離開，你也可以經由 Setup > Defaults > Editor 更換）。

以下是 ~/.config 裡關鍵檔案的清單與用途：

檔案用途~/.config/hypr/hyprland.lua Hyprland 主設定，載入 Omarchy 預設值加上你下方的覆寫檔。深入了解 Hyprland 設定。~/.config/hypr/bindings.lua 你自己的快捷鍵，以及對預設值的覆寫。~/.config/hypr/monitors.lua 控制螢幕、解析度與擺放位置。~/.config/hypr/input.lua 控制鍵盤配置、滑鼠與觸控板設定。~/.config/hypr/looknfeel.lua 控制間隙、邊框、動畫與其餘外觀。~/.config/hypr/autostart.lua 控制登入後自動啟動的額外行程。~/.config/omarchy/shell.json 控制 Omarchy 殼層：狀態列位置、版面與小工具，以及螢幕保護、鎖定與閒置計時。~/.config/foot/foot.ini 控制你的終端機（預設是 foot）。~/.XCompose 定義快速輸入表情符號與姓名信箱自動補全。改完後記得執行 omarchy-restart-xcompose。

如果你改了很多東西，把整套點檔備份起來是個好主意，Stow 是很好用的工具。

登入時自動啟動自己的程式

如果你想讓某些東西每次登入都跑，比方說同步Daemon、聊天軟體或自己的腳本，請把它放進 ~/.config/hypr/autostart.lua：

o.launch_on_start("my-service")

這樣該指令會成為工作階段的一部分，登出時也會被乾淨地收掉。

在系統事件上跑腳本

Omarchy 會在幾個時間點觸發鉤子（hook），你可以把自己的腳本掛上去。腳本住在 ~/.config/omarchy/hooks/<event>.d/，每個事件一個目錄，目錄裡每個可執行的檔案在事件發生時都會跑：

事件何時執行post-boot 桌面啟動後立刻post-update omarchy update 期間，套件與遷移完成後pre-refresh-pacman omarchy refresh pacman 重新同步套件設定之前theme-set 換主題後（主題名稱在 $1）font-set 換字型後（字型名稱在 $1）battery-low 電池低電量時（百分比在 $1）

每個目錄裡都已經放了一個 .sample 範例檔，展示鉤子的寫法，把檔名去掉 .sample 就能啟用。想把寫在別處的腳本裝進來，可以用 omarchy hook install post-boot ~/my-hook，它會複製進去並加上可執行權限。

新增自己的選單項目

Omarchy 選單（Super + Space）可以透過編輯 ~/.config/omarchy/extensions/omarchy-menu.jsonc 新增自訂列。項目以點分隔的 id 鍵入，id 決定它在樹中的位置，所以 personal 會出現在根選單，personal.notes 會出現在它裡面：

"personal": {"icon":"","label":"Personal"}, "personal.notes": {"icon":"󰎞","label":"Notes","action":"omarchy-launch-editor ~/notes"},

沿用既有 id 就會覆寫那一列，而不是新增。該檔案用註解寫明了全部可用欄位。

新增自己的 shell 匯出、函式與別名

Omarchy 內建了一堆順手的別名與函式，但想加自己的東西非常常見。別名、函式與匯出（export）都請加在 ~/.bashrc，這個檔案更新時不會被覆寫。想改 Omarchy 預設值，加在這裡也很安全。

動到 Omarchy 內部檔案

聽我說，這是你的電腦，你想怎樣都行，但我會建議不要直接改 /usr/share/omarchy 裡的檔案。它們屬於 Omarchy 的 pacman 套件，下次更新就會被覆寫。比較好的做法是在 ~/.config/* 裡覆寫你不喜歡的預設值。

幾乎所有東西都能這樣改，比方說預設快捷鍵。只要編輯 ~/.config/hypr/bindings.lua，把 Obsidian 換成 Joplin（用 omarchy-pkg-add joplin-bin 安裝）：

hl.unbind("SUPER + SHIFT + O") o.bind("SUPER + SHIFT + O", "Joplin", "joplin-desktop")

如果你堅持要動內部檔案，請經由 Update > Channel > Dev 切到 dev 通道。它會把 Omarchy 連結到 ~/omarchy 的 git checkout，裡面的東西任你改，沒人會管你！

重置所有修改

如果把設定玩壞了，隨時可以經由 Omarchy 選單的 Update > Config 回到預設值，或執行 omarchy reinstall configs 重置全部設定。
