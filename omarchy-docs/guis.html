圖形應用程式

Files

Files（Nautilus）是圖形檔案管理員。Super + Shift + F 開啟它，Super + Shift + Alt + F 會在終端機目前所在的目錄開啟它，省下大量點選。Ctrl + L 可直接輸入路徑，對任何檔案按 Space 可不開啟檔案直接快速預覽。

插入 USB 隨身碟或 SD 卡會自動掛載，直接出現在側欄。若要做更進階的事，例如格式化磁碟、檢查 SMART 健康狀態、建立分割區，請從應用程式啟動器（Super + Space）開啟 Disks。

雙擊開啟遵循合理的預設：圖片用 imv 開啟，影片用 mpv，PDF 用 Document Viewer，純文字用 Neovim。

Obsidian

Obsidian 是免費且高度可擴充的筆記應用程式，以簡單的 Markdown 檔案儲存。

Obsidian 無論個人、商業或非營利用途一律免費。

Obsidian 另有付費附加服務，可與 iOS 與 Android 行動應用程式同步（https://obsidian.md/pricing）。

以 Super + Shift + O 啟動 Obsidian。若要使用主題同步，必須在設定中選取 Omarchy 主題。

Omawrite

Omawrite 是 Omarchy 自家的極簡 Markdown 寫作應用程式。沒有 vault，沒有外掛，只有你跟文字。

以 Super + Shift + W 啟動 Omawrite。

Pinta

Pinta 是基本影像編輯工具，適合裁剪、縮放與其他基本操作。別期待它是 Photoshop 替代品，但它仍有魔術棒與圖層！

透過應用程式啟動器（Super + Space）啟動 Pinta。

Aether

Aether 是主題製作應用程式，可以從背景圖片萃取色彩並做成完整協調的主題。這是自製主題最簡單的方法。

透過應用程式啟動器（Super + Space）啟動 Aether。

LocalSend

LocalSend 可在同一網路中傳檔給其他執行該應用程式的裝置，類似 Apple 的 AirDrop。而且它是跨平台的，可以跟 Windows、macOS、Android、iOS，當然還有 Linux 互傳。

可用 Super + Ctrl + S 開啟 Share 選單，或在 Omarchy 選單的 Trigger > Share 下找到。它提供四個選項：

Clipboard 把剪貼簿內容當成文字檔傳送。適合把連結或片段傳到手機，不必再寄信給自己。

File 開啟檔案選擇器，一次可選多個檔案。

Folder 傳送整個目錄。

Receive 開啟 LocalSend 主程式，讓別台裝置可以傳東西給你。

同樣的事在終端機可用 omarchy share clipboard、omarchy share file [path] 與 omarchy share folder [path] 完成。路徑省略時會開啟選擇器。

也可以直接從檔案管理員傳送：在 Nautilus 對選取項目按右鍵，選 Send via LocalSend。

Omarchy 的防火牆預設全關，只開放 LocalSend 的連接埠，所以全新安裝就能直接用。請見 security。

LibreOffice

LibreOffice 是完整的辦公室套裝，包含文書、試算表、簡報、繪圖等應用程式。相容於 Microsoft Office 檔案，是開啟 Word 文件的好方法。

透過應用程式啟動器（Super + Space）啟動 LibreOffice。

Omacalc

Omacalc 是 Omarchy 自家的極簡計算機，以浮動視窗開啟。

以 Super + Ctrl + Q 啟動 Omacalc（若鍵盤有計算機鍵也可直接按）。

Signal

Signal 是 E2E 加密通訊的先驅，適合不想經過大型科技集團的通訊選擇。

以 Super + Shift + G 啟動 Signal。它不是預設安裝的，第一次按下該快捷鍵時 Omarchy 會先幫你安裝（也可在 Omarchy 選單的 Install > Service 下找到）。

mpv

mpv 是簡單快速的媒體播放器，幾乎什麼來源、什麼格式都能播。看影片的好選擇。

透過應用程式啟動器（Super + Space）啟動 mpv，或直接在檔案管理員雙擊影片。

OBS Studio

OBS Studio 可錄製或串流多路輸入的影片。可以把螢幕錄影、網路攝影機與麥克風混在一起。Omarchy 的示範影片就是用它錄的。

透過應用程式啟動器（Super + Space）啟動 OBS Studio。

Kdenlive

Kdenlive 是優秀的影片剪輯軟體。適合把 OBS Studio 錄好的影片加工後再分享。

透過應用程式啟動器（Super + Space）啟動 Kdenlive。

Omacut

Omacut 是 Omarchy 自家的極簡影片裁剪工具。只需要剪掉片段頭尾時，用它比開完整剪輯軟體快得多。

透過應用程式啟動器（Super + Space）啟動 Omacut。
