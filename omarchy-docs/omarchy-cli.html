Omarchy 命令列介面

Omarchy 通常透過快捷鍵與 Omarchy 選單（Super + Space）操作，但你也可以透過 omarchy 命令列介面（Command-Line Interface，簡稱 CLI）控制它。當你請 AI 代理人（AI agent）協助你自訂或設定系統時，這特別有用。

CLI 可以存取選單與其他管道使用的全部內部工具。在終端機執行 omarchy 即可看到所有可用功能。

大致長這樣：

~ ❯ omarchy
Omarchy command center
Usage:
omarchy <command> [args...]
omarchy commands [--all] [--json] [--check]
omarchy <group> --help
omarchy <group> <command> --help
Common commands:
omarchy update              Update Omarchy and system packages
omarchy theme list          List available themes
omarchy theme set <name>    Apply a theme
omarchy font list           List available fonts
omarchy screenshot          Take a screenshot
omarchy debug               Print debugging information
Groups:
agent          AI coding agent usage data
audio          Audio input and output controls
bar            Omarchy shell bar layout and settings
battery        Battery status helpers
bluetooth      Bluetooth device controls
branch         Omarchy git branch management
branding       About and screensaver branding
brightness     Display and keyboard brightness
capture        Screenshots and screen recording
channel        Omarchy release channel management
clipboard      Clipboard helpers
cmd            Command and shortcut helpers
config         System configuration helpers
debug          Diagnostics and support logs
...

每個群組都可以再深入查看：

~ ❯ omarchy capture
Capture commands — Screenshots and screen recording:
omarchy capture qr                                   Decode a QR code from a screenshot region
omarchy capture screenrecording [--fullscreen] [--with-desktop-audio] [--with-microphone-audio] [--with-webcam] [--webcam-device=<device>] [--webcam-size=<small|medium|large>] [--resolution=<size>] [--stop-recording]  Start or stop screen recording
omarchy capture screenrecording with webcam          Pick a webcam and start a screen recording with it
omarchy capture screenshot [smart|region|windows|fullscreen] [slurp|copy|save] [--editor=<name>]  Take a screenshot
omarchy capture text                                 Extract text from a screenshot region with OCR
omarchy capture webcam resize <smaller|larger|reset|small|medium|large>  Resize the active webcam recording overlay

每個指令都支援 --help，不論是整個群組（omarchy capture --help）或單一指令（omarchy capture screenshot --help）。

從終端機開啟選單（Opening the menu from the terminal）

Omarchy 選單也可以寫成腳本，方便你綁定自己的快捷鍵。omarchy menu 可在根目錄開啟選單，直接指定樹狀路徑可跳到任意位置：omarchy menu summon style.theme 會直接跳到佈景主題選擇器，omarchy menu toggle system 會開啟系統選單（若已開啟則關閉），omarchy menu close 則將選單收起。
