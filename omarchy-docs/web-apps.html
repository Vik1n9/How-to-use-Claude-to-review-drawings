網頁應用程式

你可以用 Omarchy 選單（Super + Space）的 Install > Web App 新增自己的網頁應用程式。它會問你應用程式名稱、應用程式 URL，以及圖示 URL（若無法透過 favicon 取得）。許多熱門網頁應用程式的高品質 PNG 圖示可在 Dashboard Icons 找到。

之後即可透過應用程式啟動器（Super + Space）開啟，使用漂亮的無框網頁應用程式視窗。

若要移除網頁應用程式，到 Omarchy 選單的 Remove > Web App 即可。

建議先用一般瀏覽器登入所有帳號，再使用網頁應用程式捷徑。輕量外框跟 1password 處得不好，所以直接先登入最省事。

所有這類網頁應用程式的快捷鍵都可以在 ~/.config/hypr/bindings.lua 修改。

在網頁應用程式中，可用 Shift + Alt + L 把目前網址複製到剪貼簿。

預設 Omarchy 已內建一系列應用程式：

HEY

HEY 是電子郵件與行事曆服務，適合受夠 Gmail、Outlook 或 Apple Mail 的人。它出自 Omarchy 發源地 37signals。

以 Super + Shift + E 啟動 HEY Email，以 Super + Shift + Alt + E 直接寫新郵件，以 Super + Shift + C 啟動 HEY Calendar。

Basecamp

Basecamp 是專案管理服務，幫助小團隊跑得更快、產出更多。不必再東拼西湊 Trello、Slack、Asana、Notion，有了 Basecamp 全部都在同一處。它出自 Omarchy 發源地 37signals。

以應用程式啟動器（Super + Space）啟動 Basecamp。

ChatGPT

ChatGPT 是全球最受歡迎的 AI 聊天機器人。

以 Super + Shift + A 啟動 ChatGPT。

Grok

Grok 是 xAI 的聊天機器人。

以 Super + Shift + Alt + A 啟動 Grok。

WhatsApp

WhatsApp 是全球最受歡迎的通訊服務之一，網頁版在 Linux 上是很好的選擇。

以 Super + Shift + Alt + G 啟動 WhatsApp。

Google apps

Google Messages、Google Photos、Google Maps 與 Google Contacts 也都內建為網頁應用程式。

以 Super + Shift + Ctrl + G 啟動 Google Messages，以 Super + Shift + P 啟動 Google Photos，以 Super + Shift + S 啟動 Google Maps。Google Contacts 可透過應用程式啟動器（Super + Space）開啟。

X

X 是新聞爆發的地方。

以 Super + Shift + X 啟動 X，以 Super + Shift + Alt + X 直接寫新貼文。

YouTube

YouTube 是全球最受歡迎的影音平台。

以 Super + Shift + Y 啟動 YouTube。

Zoom

Zoom 是美國最受歡迎的視訊會議系統，全球連線品質優秀。免付費帳號可開 40 分鐘會議。Omarchy 包裝的是 Zoom 的網頁客戶端，Zoom 會議連結會直接用它開啟。

以應用程式啟動器（Super + Space）啟動 Zoom。

Discord

Discord 是多數遊戲與開源社群的聚集地，Omarchy 自己的社群也在上面。

以應用程式啟動器（Super + Space）啟動 Discord。
