常見問題

如何切換鍵盤配置？

編輯 ~/.config/hypr/input.lua，加入以下設定，即可用 Left Alt + Right Alt 切換配置：

hl.config({ input = { -- Use multiple keyboard layouts and switch between them with Left Alt + Right Alt kb_layout = "us,fr", kb_options = "compose:caps,shift:both_capslock_cancel,grp:alts_toggle", }, })

設定多組配置後，頂欄會自動顯示目前鍵盤配置（也可點選切換）。

如何把時鐘改為 12 小時制？

在頂欄對時鐘按右鍵，可循環切換常用格式，含 12 小時制。也可直接設定：

omarchy bar set omarchy.clock format "dddd h:mm AP"

將顯示 Sunday 10:55 AM。

如何變更時區？

在 Omarchy 選單執行 Update > Timezone，從清單挑選。若時區正確但時鐘漂移，Update > Time 會重啟時間同步。

如何改 DNS、分享 Wi-Fi 或測速？

都在 networking 一節。

如何測磁碟速度？

Trigger > Speed Test > Disk Speed Test 可測量磁碟即時讀寫速度，或在終端機執行 omarchy disk speedtest。

為什麼 Chromium 登不進 Google 帳號？

純開源 Chromium build 未內建 Google 帳號登入所需的 OAuth 憑證。在 Omarchy 選單執行 Install > Service > Chromium Account 加入憑證，重啟瀏覽器即可登入。

如何新增印表機？

列印開箱即用，每台印表機需從 App 啟動器（Super + Space）的 Print Settings 自行新增。

選擇 Add，稍候搜尋：USB 連接的印表機與多數網路印表機會自動找到。若沒列出，選 Network Printer > Internet Printing Protocol (ipp) 並輸入位址，印表機螢幕或其網頁會標示，通常如 192.168.1.50，佇列為 ipp/print。按 Forward 會提供驅動程式，現代印表機用 driverless IPP Everywhere 設定檔最佳，舊機型則用其專屬驅動。

對印表機按右鍵選 Set as Default 可設預設印表機，Properties 可設紙張尺寸、雙面與品質。

自動探索（網路印表機免新增即出現）暫時關閉重作中，故第一步需手動。列印成 PDF 檔無需任何印表機。

如何更改截圖或錄影儲存位置？

若想把截圖存到 ~/Pictures/Screenshots 而非 ~/Pictures，可在 ~/.config/uwsm/env.d/ 下建檔（如 ~/.config/uwsm/env.d/capture）加入：

export OMARCHY_SCREENSHOT_DIR="$HOME/Pictures/Screenshots"

錄影同理，使用 OMARCHY_SCREENRECORD_DIR。

記得建好目標目錄並重啟 Omarchy 才會生效。

如何讓 Apple Studio Display 的喇叭＋ webcam 運作？

只接 USB C 照理該全通，實際並非如此。可靠解法是使用 WJESOG DisplayPort + USB-A => USB-C cable，喇叭與 webcam 即正常運作。

Omarchy 對 Apple Displays（Studio 與 XDR）內建亮度控制，可用鍵盤亮度鍵調整。

如何移除多餘的預裝軟體？

若不想留 Obsidian、LibreOffice 等預裝程式，移除很容易。

執行 Remove > Package 可看到所有已安裝套件，用 tab 選取想移除者，按 return 開始移除。

或用 Omarchy 選單的 Remove > Web App 移除不要的預裝 web apps。

或執行 Remove > Preinstalls 一次清掉所有預裝附加品：web apps、TUIs 與選用應用程式。啟動它們的 hotkeys 會一併消失，~/.config/hypr/bindings.lua 留給你填入自己的綁定。

錯誤與損壞見 Troubleshooting 一節。
