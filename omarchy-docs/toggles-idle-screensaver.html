開關、閒置與螢幕保護程式

每天切換的很多東西並不是設定，而是開一小時、關一小時的模式：深夜工作的夜燈（night light）、簡報中的勿擾（do not disturb）、看片時的保持清醒（stay awake）。Omarchy 稱之為開關（toggle），用法全都一樣——一個快捷鍵、一個選單項目、一道指令，打到同一個開關上。

開關選單（The toggle menu）

Super + Ctrl + O 直接開啟 Trigger > Toggle，或從 Omarchy 選單（Super + Space）走過去。清單裡每項都是開關，不必管狀態存在哪裡，翻就對了。

終端機裡同一套開關是 omarchy toggle <thing>，單獨執行 omarchy toggle 可看全部分組。

開關快捷鍵指令
夜燈（Night light）Super + Ctrl + Nomarchy toggle nightlight
靜音通知（Silence notifications）Super + Ctrl + ,omarchy toggle notification silencing
保持清醒（Stay awake，不閒置鎖定）Super + Ctrl + Iomarchy toggle idle
當機擷取（Crash capture）—omarchy toggle crash-capture
螢幕保護程式（Screensaver）—omarchy toggle screensaver
選單列（Menu bar）Super + Shift + Spaceomarchy toggle bar
觸控板（Touchpad）XF86TouchpadToggleomarchy toggle touchpad
觸控螢幕（Touchscreen）—omarchy toggle touchscreen
暫停（Suspend）—omarchy toggle suspend
混合顯示卡（Hybrid GPU）—omarchy toggle hybrid gpu

觸控板、觸控螢幕與混合顯示卡開關放在 Trigger > Hardware（Super + Ctrl + H）下而非 Toggle 下，因為只在你真有該硬體時出現。觸控板與觸控螢幕開關在 Hyprland 重新載入後依然有效——被停用的裝置名稱會存進小狀態檔，Hyprland 啟動時讀檔再停用一次。

Toggle 選單還帶幾個不是 omarchy toggle 指令、但行為相同的項目：頂欄電池百分比、workspace 版面（Super + L）、視窗間隙（Super + Shift + Backspace）與單視窗正方形比例（Super + Ctrl + Backspace）。

多數開關只是一個放在 ~/.local/state/omarchy/toggles/ 下的旗標檔。若想在腳本中分支判斷，用 omarchy-toggle-enabled 拿 exit code，不必自己找檔：

omarchy-toggle-enabled screensaver-off && echo "screensaver is off"

旗標以關閉狀態命名——screensaver-off、suspend-off、bar-off——檔案存在即代表該功能停用。

頂欄指示燈（Indicators in the bar）

模式開啟時，頂欄中央時鐘旁會出現小圖示，那就是指示燈（indicators）小工具，承載聽寫、螢幕錄影、待辦提醒、夜燈、勿擾與保持清醒。

未啟用的指示燈預設隱藏。把滑鼠移到附近會以半透明淡入，可直接點開，不必背快捷鍵；已啟用的點一下即關掉。若想全部常駐，把 ~/.config/omarchy/shell.json 中 omarchy.indicators 項的 alwaysShow 設為 true 即可，頂欄小工具怎麼設定見頂欄（the top bar）。

夜燈（Night light）

Super + Ctrl + N 把螢幕暖到 4000K，再按一次回到 6500K。背後由 hyprsunset 驅動，開關會在它尚未執行時幫你啟動。

預設 hyprsunset 對螢幕什麼都不做。~/.config/hypr/hyprsunset.conf 出貨時是 identity 設定檔， display 在你要求變暖前原封不動。若想按時鐘自動切換，換成時間設定檔：

profile {
time = 20:00
temperature = 4000
}

再到 ~/.config/hypr/autostart.lua 加一行 o.launch_on_start("hyprsunset")，讓它登入即啟動。開關用的 4000K／6500K 配對是固定的，想要別的色溫請改設定檔。

勿擾（Do not disturb）

Super + Ctrl + , 靜音通知。開啟期間不彈 toast，頂欄掛著划掉的鈴鐺，提醒你桌面為何安靜。

但什麼都不會丟。被靜音的通知會直接寫進通知歷史，正好是你回來後想補看的紀錄。用 Super + Shift + Alt + , 開啟，通知的其餘故事見通知（notices）。

兩種訊息照樣穿透：Omarchy 對你剛做之事的確認 toast（「Theme changed」、「Screenshot saved」），以及從命令列發出的重大警報。把什麼都標成重大、硬要插隊的聊天應用不算。

閒置（Idle）

Omarchy shell 有閒置行為，時間是 ~/.config/omarchy/shell.json 頂層 idle 區塊：

{
"version": 1,
"idle": {
"screensaver": 150,
"lock": 300
}
}

兩個數字都是從你進入閒置起算的秒數，而非彼此相加。因此預設是閒置兩分半進螢幕保護程式，五分鐘進鎖定畫面，不論螢幕保護程式有沒有跑過。存檔後 shell 即時套用新時間。

若在鎖定死線前關掉螢幕保護程式，視為活動，待定的鎖定即取消，不會因看一眼機器就被鎖在門外。

想徹底不因閒置鎖定，用 Super + Ctrl + I 或 omarchy toggle idle 開啟保持清醒（stay awake），頂欄出現咖啡杯圖示。長簡報或想盯著跑的建置前先敲下去，結束再敲回來。omarchy toggle idle status 會以 JSON 印出目前狀態，方便腳本取用。

這裡管的是鎖定與螢幕保護程式，不是電源。暫停與休眠是另一套，見系統睡眠（system sleep）。

螢幕保護程式（The screensaver）

Omarchy 的螢幕保護程式是跑過隨機文字特效的 ASCII 藝術，每台螢幕各一具。任意按鍵或滑鼠移動即退出。

可從 System > Screensaver（Super + Esc）隨叫隨到，即使閒置螢保已關也會強制升起。預設沒有綁快捷鍵。

omarchy toggle screensaver 關的是閒置版，若想從工作直達鎖定就關掉它。它需要一個懂得設定的終端機——Alacritty、Foot、Ghostty 或 Kitty——若預設終端機不是這幾套，它會直說。

它畫的標誌可以換，到 Style > Screensaver 上傳 png 或 svg，Omarchy 會轉成 ASCII，詳見品牌（branding）。

鎖定畫面（The lock screen）

Super + Ctrl + L 鎖機，跑 Omarchy shell 的鎖定畫面：清空顯示、把鍵盤配置重置回第一套（以免用錯字母表輸密碼），若 1Password 在跑，出門前一併上鎖。

鎖定畫面收密碼，設好指紋後也收指紋，認證的其他招式見硬體認證（hardware authentication）。
