遊戲

Omarchy 不只為了生產力，也是為了好玩，而有什麼比遊戲更好玩？Omarchy 內建一整套遊戲選項：Steam 與 RetroArch 負責原生與懷舊，Battle.net、Lutris 與 Heroic 負責非 Steam 商店，Moonlight 負責 PC 串流，Xbox Cloud Gaming 加 NVIDIA GeForce NOW 負責雲端，還有長青的 Minecraft。

多虧 Valve 在 Proton 相容層上的出色工作，Linux 上已有數以萬計可玩的現代遊戲。對了，你知道 Steam Deck 跑的其實就是 Arch 嗎！

所有遊戲安裝程式都在 Omarchy 選單（Super + Space）的 Install > Gaming 下。若想反悔，到 Remove > Gaming 移除。

Steam

到 Omarchy 選單（Super + Space）選 Install > Gaming > Steam 安裝 Steam。

裝好之後，以 Super + Space 啟動 Steam。

注意 Steam 可能需要 10到20秒啟動，而且載入時不會給任何視覺回饋。

RetroArch

到 Omarchy 選單（Super + Space）選 Install > Gaming > RetroArch 安裝 RetroArch。它附帶完整的 libretro 核心，所以經典主機全包。

RetroArch 已預先設定好漂亮的 CRT Royale 著色器，重現完美的懷舊觀感。

上手步驟：

把 BIOS 檔丟進 ~/Games/bios，ROM 丟進 ~/Games/roms。

以 Super + Space 啟動 RetroArch 並輸入 retro。

掃描 ~/Games/roms 目錄即可開玩。

也可以用 Install > Gaming > RetroArch Game Launcher 為喜愛的遊戲在啟動器建立專屬項目，挑核心與 ROM，之後從 Super + Space 直接進遊戲。

Xbox Cloud Gaming

到 Omarchy 選單（Super + Space）選 Install > Gaming > Xbox Cloud Gaming 安裝 Xbox Cloud Gaming 網頁應用程式。它「只是」該服務的網頁應用程式，但啟動快且跑 1080p 很順。

若你已有 Xbox Game Pass，這是玩 Fortnite 等無法在 Linux 原生跑的遊戲的好方法。

NVIDIA GeForce Now

到 Omarchy 選單（Super + Space）選 Install > Gaming > NVIDIA GeForce NOW 安裝雲端遊戲服務 NVIDIA GeForce NOW。同樣是玩 Linux 沒有原生版遊戲的好方法。

Minecraft

到 Omarchy 選單（Super + Space）選 Install > Gaming > Minecraft 安裝 Minecraft。

跟 Steam 一樣注意，登入或啟動後下一個畫面出現前可能要等一會，等待時不會有任何回饋。

Xbox Controllers

到 Omarchy 選單（Super + Space）選 Install > Gaming > Xbox Controllers 安裝藍牙 Xbox 手把支援。透過藍牙（Super + Ctrl + B）配對手把，之後所有遊戲都能用。若只用 USB-C 有線連接則不需要這個。

Moonlight（從 PC 串流遊戲） Moonlight (Game streaming from a PC)

Moonlight 客戶端在 Omarchy 預裝，所以只要遠端 Windows PC 跑著 Sunshine 就能立刻串流。透過 Super + Space 啟動 Moonlight。

若 Omarchy 主機與遠端遊戲 PC 都是有線連接，體驗跟本機遊玩幾乎沒有差別。解析度直接開到原生，更新率設 120Hz，位元率拉滿，這是在 Linux 玩 Fortnite 這類競技射擊遊戲最好的方法。

也可以把 Omarchy 主機變成被串流端，執行 omarchy install service sunshine，會安裝 Sunshine 並為區域網路與 Tailscale 開啟 Moonlight 串流連接埠。

Battle.net

到 Omarchy 選單（Super + Space）選 Install > Gaming > Battle.net 安裝 Battle.net。這樣 Diablo、Starcraft 與 World of Warcraft 等作品就能以獨立安裝、跑在 GE-Proton 下，不需要 Steam、Lutris 或 Heroic。

Lutris（Windows 遊戲） Lutris (Windows games)

到 Omarchy 選單（Super + Space）選 Install > Gaming > Lutris 安裝 Lutris。Lutris 適合玩 EA 與 Ubisoft Connect 等商店、上面沒有專屬安裝程式的 Windows 遊戲。

安裝過程有點頓，看起來像沒反應的時候請耐心等，它在背景有在做事。

Heroic Launcher（Epic Games） Heroic Launcher (Epic Games)

到 Omarchy 選單（Super + Space）選 Install > Gaming > Heroic (Epic Games) 安裝 Heroic Launcher。Heroic 可跑 Epic Games 旗下不依賴反作弊的遊戲，例如 OddSparks，外加 GOG 與 Amazon Prime Gaming 的遊戲。可惜這代表沒有 Fortnite 也沒有 Rocket League，在 Tim Sweeney 登陸 Linux 之前，這已經是最接近的解法。

跟 Lutris 一樣，安裝遊戲時可能感覺慢頓，請給它一點時間。
