安裝其他套件

Arch 的軟體套件極多，不論官方軟體庫或 Arch 使用者軟體庫（Arch User Repository，簡稱 AUR），幾乎任何類型的軟體都找得到。

使用方式也非常簡單。安裝新的 Arch 套件時，只要開啟 Omarchy 選單（Super + Space），依序點選 Install > Package，再輸入想要的套件名稱即可，系統會自動對全部套件做模糊過濾。你也可以在終端機手動執行 omarchy pkg add [package]。

AUR 也一樣，只要使用 Install > AUR。但請記得，AUR 並沒有經過 Arch 團隊審核，它就像 RubyGems 或 npm，任何人都可以上傳。

如果想移除套件，可以使用 Omarchy 選單中的 Remove > Package，它會一併移除套件、設定檔與相依套件。你也可以在終端機手動執行 omarchy pkg drop [package]。
