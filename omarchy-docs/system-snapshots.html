系統快照

每次 Omarchy 更新都會自動建立快照。若想手動建立，可用 omarchy-snapshot create。

要開機並還原快照，從 Limine boot loader 選擇快照。（若目前開機直接進入 Omarchy 解密畫面，需先經 BIOS 選擇 Limine 作為開機選項。）

在該畫面依日期與版本選擇想開機的快照。快照當時的 Omarchy 版本顯示於左下角。

進入後會跳出通知，告知你正處於可開機快照中，點選即開始還原流程。或直接使用 omarchy-snapshot restore。

還原的是 root 檔案系統，不含 /home。因此可用於回滾損壞的系統更新，但無法救回遺失的個人檔案。

這也表示 ~/.config 目錄維持不動。若回滾到較舊版的函式庫或應用程式，而其設定檔已用新格式儲存，就得手動處理。

注意：此功能僅適用於使用 Limine boot loader 的安裝，即 Omarchy 2.0 起的預設值。若用 GRUB 或 systemd-boot 則無此功能。

跳過開機選單

若從不碰開機選單、只想直達解密畫面，在 Omarchy 選單執行 Setup > Direct Boot。該動作新增一筆直接指向 Omarchy 的 EFI entry，韌體開機即直入，不經 Limine。

代價如上所述：開啟 direct boot 後，要進快照就得先從 BIOS 開機選單選 Limine。再執行一次 Setup > Direct Boot 可刪除該 entry，回到經 Limine 開機。部分韌體不接受自訂 EFI entries，故該設定在 American Megatrends 與 Apple firmware 上拒絕執行。
