自製主題

自製主題（Making your own theme）：你可以在 ~/.config/omarchy/themes 加入自己的主題。複製一份現有主題當底（在 /usr/share/omarchy/themes 查看），再盡情微調。只要主題在該資料夾內，就會出現在主題選擇選單中。

主要要改的檔案是 colors.toml。它定義的色票會用來產生以下設定：終端機（Foot／Alacritty／Ghostty／Kitty）、btop、Chromium、Hyprland、Neovim、Helix、VSCode、Obsidian，以及整個 Omarchy shell（頂欄、選單、通知、OSD、鎖定畫面）。

你也可以用內附的 Aether 應用程式以可愛的圖形介面開新主題，玩配色、搜尋桌布。以應用程式選單的 Super ＋ Alt ＋ Space 啟動它。

自己寫的主題可以裝什麼

寫在 ~/.config/omarchy/themes 的主題愛裝什麼就裝什麼——那是你的機器、你的檔案，Omarchy 照單全收。

以 omarchy theme install 從他人 repo 安裝的主題，只保留與顏色有關的，其餘少數會在你機器上執行程式碼的檔案會被丟掉：任何 .lua 檔、終端機設定（alacritty.toml、foot.ini、ghostty.conf、kitty.conf）與 vscode.json。主題的 hyprland.lua 是合成器在登入時執行的 Lua，終端機設定指定終端機啟動的程式，vscode.json 指定要安裝的 VSCode 擴充。裝別人的主題只該改變桌面的長相，絕不該改變它會執行什麼。

其餘一切照主題作者所寫保留——btop.theme、chromium.theme、helix.toml、icons.theme、shell.toml、桌布與預覽圖全都留下。只有被丟掉的部分會以你機器的 colors.toml 重新產生。

Omarchy 以主題內有無自己的 git repo 區分兩者，omarchy theme install 複製時留下的就是它。因此自己寫的主題永遠是你的，從網路上拉的永遠只算配色。

淺色模式

製作淺色主題時，在 colors.toml 頂部設定 mode = "light"。之後所有應用程式都會自動配對淺色模式。（舊方法——在主題根目錄丟一個名為 light.mode 的空檔——仍然有效。）

圖示配色

若想讓檔案管理員圖示跟著主題配色，加入名為 icons.theme 的檔案，寫入想用的圖示集名稱。預設選項為：Yaru Yaru-blue Yaru-dark Yaru-magenta Yaru-olive Yaru-prussiangreen Yaru-purple Yaru-red Yaru-sage Yaru-wartybrown Yaru-yellow。

解鎖圖

附有 unlock.png 與 preview-unlock.png 的主題會列在 Style > Unlock 下。你的 unlock.png 最好是透明 png。預覽圖可以 omarchy plymouth preview 製作。

Omarchy 沒覆蓋的應用程式怎麼配色

若用的應用程式不在該清單中，你可以自己寫模板（template）教 Omarchy 為它配色。在 ~/.config/omarchy/themed/ 丟一個檔，檔名為它要產生的設定檔名加上 .tpl 副檔名，內容以 {{ background }}、{{ foreground }}、{{ accent }}、{{ red }}、{{ color0 }} 至 {{ color15 }} 等其餘色票作佔位符。每次切換主題，該檔就會以當下主題配色重新產生。

該資料夾內有一份完整註解的 alacritty.toml.tpl.sample 可複製，列出所有可用變數，外加給顏色不要 # 或要十進位 RGB 的應用程式用的 _strip 與 _rgb 修飾。你的模板優先於 Omarchy 內建，因此也能用它覆寫內建應用程式的配色方式。

發布你的主題

若想發布主題給別人用，需放在公開 git 伺服器如 GitHub。別人即可經由 Omarchy 選單的 Install > Style > Theme 以該 URL 安裝。建議遵循 omarchy-[themename]-theme 命名慣例，安裝後主題在選擇選單中會正確顯示為 [themename]。

剩下的 [themename] 會成為主題目錄名，因此必須是 Omarchy 能安全經手的字串：開頭須為字母、數字或底線，其餘可為字母、數字、.、_、＋、-。大寫會幫你轉小寫，其餘——空格、引號、非英文字符——一律在安裝時拒絕，而非硬轉成目錄名。因此 omarchy-tokyo-night-theme、omarchy-flexoki_light-theme、omarchy-c++-theme 都裝得起來。

記住，從 repo 安裝後，其附帶的 .lua、終端機設定或 vscode.json 會被丟掉，因此別把主題蓋在那些東西上。

以向 omarchy-site repo 發 pull request，可把你的主題加入額外主題頁。
