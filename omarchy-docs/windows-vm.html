Windows 虛擬機

Omarchy 提供了一種透過 Docker 虛擬機（VM）執行 Windows 的簡便方式。你可以從 Omarchy 選單（Super + Space）使用 Install > Windows 安裝。

你的電腦需要支援 KVM 虛擬化（virtualization），多數電腦都有，但有時會在 BIOS 裡被關掉，安裝程式會在這種情況下提醒你。你還需要準備磁碟空間：給 Windows 多大，就要再多留約 10GB 放映像檔本身。

安裝程式會詢問要分多少記憶體（RAM）、幾顆 CPU 核心、多大磁碟（64GB 以上是比較合理的下限），以及 Windows 的使用者名稱與密碼。帳密留白就會得到 docker／admin。下載需要一段時間，10到15分鐘都算正常，你可以在瀏覽器開啟 http://127.0.0.1:8006 追蹤進度。瀏覽器在開啟主控台前，會要求輸入相同的使用者名稱與密碼。

使用方式

安裝完成後，從應用程式啟動器啟動 Windows。如果虛擬機還沒跑，它會先啟動，再透過 RDP（遠端桌面協定）連線，全螢幕呈現。冷啟動時請給它 15到30秒。

RDP 連線會攜帶音效、麥克風與共用剪貼簿，所以在 Linux 與 Windows 之間複製文字可以直接用。解析度會跟著你的視窗走，Omarchy 也會把顯示縮放傳進去，在 HiDPI 螢幕上不會糊成一團。

關掉 RDP 視窗時，虛擬機會自動關機。如果你想讓它繼續跑，比方說裡面有東西還在工作，可以改用 omarchy windows vm launch --keep-alive 啟動。

其餘控制都在同一個指令下：

omarchy windows vm status # 它在跑嗎？omarchy windows vm stop # 關機omarchy windows vm launch # 啟動並連線

共用檔案

你家目錄下的 ~/Windows 目錄會自動共用給虛擬機。想讓 Windows 存取的檔案就放那裡。虛擬機看不到你檔案系統的其他部分，所以 Windows 那一側就算有惡意軟體也傷不到你。它自己的虛擬磁碟放在 ~/.windows。

這些家目錄路徑各自留在自己的檔案系統上。它們也可以是指向你擁有之目錄的符號連結（symlink），當虛擬磁碟放在更大的硬碟上時很有用。安裝程式量測的是實際存放 ~/.windows 的那個檔案系統的可用空間，不一定是你家目錄所在的檔案系統。

磁碟目錄與共用目錄請保持為兩個不重疊的獨立目錄。移除時會刻意清空磁碟目錄，但保留共用目錄。刪除前一刻，Omarchy 會執行有範圍限制的包容檢查（bounded containment check），若檢查逾時或無法證明兩棵目錄樹彼此分離，就拒絕刪除。

虛擬機啟動前，Omarchy 會開啟並鎖定（pin）這兩個目錄，再把確切的目錄 inode 綁定掛載（bind-mount）到 /var/lib/omarchy/windows/mounts 底下每位使用者專屬的錨點。Docker 只看得到那些 root 保護的錨點。這樣既保留自訂磁碟位置，又能防止另一個以你的身分執行的行程，在特權容器取用路徑之前偷換被檢查過的路徑。既有磁碟與共用目錄在遷移期間會被收緊為 mode 0700，讓本機其他帳號無法瀏覽其內容。

虛擬機的連接埠只綁定在 localhost，所以區網上的任何裝置都碰不到這台 Windows。網頁主控台也要求輸入設定好的 Windows 使用者名稱與密碼，防止本機另一個帳號透過 8006 埠操控虛擬機。

限制與授權

這個架構沒有 GPU 直通（passthrough），所以不適合玩遊戲或剪片。用來跑 Microsoft Office 或其他非用不可的軟體倒是很好用。

安裝的是未啟用的 Windows 11 Pro，你需要自己的授權金鑰才能使用被鎖住的功能。

如果這台電腦出廠搭載 Windows，即使裝了 Omarchy，OEM 金鑰仍留在韌體裡。用 omarchy windows key 可以印出來。那把金鑰綁定在這台機器上，可以啟用重裝在這台硬體上的 Windows，但通常無法啟用虛擬機裡的 Windows。

之後想調整資源配置，可以重跑 omarchy-windows-vm install，安裝程式會依你的回答重寫虛擬機設定。compose 檔本體現在放在 /var/lib/omarchy/windows/docker-compose.yml 且屬於 root，這是刻意的，讓以你的身分執行的行程無法改寫它，進而讓特權啟動流程把你的整顆磁碟掛進容器。如果你需要手動編輯（例如掛載 USB 裝置），請用 sudo 編輯，並到 Dockur Windows 專案查看全部選項。

想整個移除，就用 Omarchy 選單的 Remove > Windows。這會刪除虛擬機磁碟與全部資料，所以請先把 ~/Windows 裡在意的東西搬出來。
