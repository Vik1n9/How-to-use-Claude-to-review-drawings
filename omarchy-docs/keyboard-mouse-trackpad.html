鍵盤、滑鼠、觸控板

Hyprland 讓你能非常細緻地設定所有輸入裝置。你可以把鍵盤連打調到超音速，也可以讓觸控板用自然捲動。全部都在 ~/.config/hypr/input.lua 裡改，Omarchy 選單（Super + Space）的 Setup > Input 也連到同一個檔案。你在那裡設的任何值都會取代 Omarchy 預設值。

範例如下：

hl.config({ input = { -- 用多組鍵盤配置，以 Left Alt + Right Alt 切換kb_layout = "us,dk", kb_options = "compose:caps,shift:both_capslock_cancel,grp:alts_toggle", -- 連打速度repeat_rate = 40, repeat_delay = 600, -- 滑鼠觸控板靈敏度（預設 0）sensitivity = 0.35, touchpad = { -- 自然（反向）捲動natural_scroll = true, -- 以雙指點擊取代右下角當右鍵clickfinger_behavior = true, -- 捲動速度scroll_factor = 0.3, }, }, }) -- 終端機裡捲快一點o.window("(Alacritty|kitty|foot)", { scroll_touchpad = 1.5 })

全部輸入選項可以去 Hyprland wiki 的 inputs 頁面查看。

預設情況下，Omarchy 把 CapsLock 當作 compose 鍵，用來快速輸入表情符號與其他補全。如果你想把 CapsLock 拿回來當大寫鎖定，可以改 kb_options 裡的 compose:caps，把 compose 鍵搬走。比方說搬到 Right Alt：

hl.config({ input = { kb_options = "compose:ralt", }, })

觸控板手勢

你也可以開啟觸控板手勢，比方說三指橫滑切換工作區：

hl.gesture({ fingers = 3, direction = "horizontal", action = "workspace" })

Dell XPS 筆電的觸覺觸控板，還可以在 Trigger > Hardware > Touchpad Haptics 下把點按力道設為 low、mid 或 high。

輸入中文、日文與其他語言

Omarchy 的每個工作階段都跑著 fcitx5 輸入法框架（input method framework），CapsLock 的 compose 連打就是靠它。也正因如此，非拉丁輸入的管線早已就緒：用 omarchy pkg add 安裝 fcitx5-mozc（日文）或 fcitx5-chinese-addons（中文）這類輸入引擎，再加裝 fcitx5-configtool，把引擎加入輸入法並設定切換按鍵即可。

把 ALT 當 SUPER 用

某些鍵盤用主要 meta 鍵（Windows 鍵或 cmd 鍵）當 SUPER 不順手，可以改成用 ALT：

hl.config({ input = { kb_options = "compose:caps,shift:both_capslock_cancel,altwin:swap_alt_win", }, })
