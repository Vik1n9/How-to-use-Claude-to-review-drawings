螢幕截圖與錄影

螢幕上能抓的東西全掛在 Print Screen 鍵上。單按是拍照，加上修飾鍵則是錄影、取色或擷取區域內文字。若鍵盤根本沒有 Print Screen 鍵，Super + Ctrl + C 會以選單形式開啟同一套功能。

快捷鍵功能
Print Screen螢幕截圖（Screenshot）
Alt + Print Screen螢幕錄影（Screenrecord，或停止錄影中者）
Super + Print Screen取色器（Colour picker）
Super + Ctrl + Print Screen從區域擷取文字
Super + Ctrl + C擷取選單（Capture menu）
Super + Ctrl + .轉檔圖片或影片

螢幕截圖（Screenshots）

按下 Print Screen 後螢幕會凍結，取景時畫面不會在你手下亂跑。拖曳方框自由框選，或點一下，截圖會自動貼合你點到的矩形——點到視窗就貼視窗，點到頂欄或空隙就抓整台螢幕。反悔了？再按一次 Print Screen 關掉選擇器。

結果一次去兩個地方：~/Pictures 目錄下的 PNG 檔，以及剪貼簿，所以你能用 Super + V 直接貼進聊天視窗。通知會帶縮圖彈出，點它（或按 Super + Alt + , 叫出最新通知），截圖會在 Tensaku（標註編輯器）中開啟，送出前可在上面畫箭頭與方框。

檔案預設落在 ~/Pictures，命名如 screenshot-2026-08-13_14-22-05.png。若想收進專屬資料夾，設定 OMARCHY_SCREENSHOT_DIR 即可（session 環境變數放哪裡見 FAQ）。目錄不存在時 Omarchy 會幫你建好，編輯器也可用 OMARCHY_SCREENSHOT_EDITOR 更換。

從終端機可用 omarchy screenshot 拍同樣的截圖，也可更明確指定：omarchy capture screenshot region 只自由框選，windows 貼合視窗與螢幕矩形，fullscreen 跳過選擇器直接抓聚焦的螢幕。第二個參數 copy 只送剪貼簿，save 只存檔。

用鍵盤操作選擇器（Driving the picker from the keyboard）

選擇器開啟時，你完全可以不用滑鼠：

按鍵功能
Return擷取反白的視窗
Ctrl + Return擷取整個螢幕
Tab / Ctrl + Tab反白下一個 / 上一個視窗
方向鍵反白該方向的視窗

方向鍵與 Tab 會把游標帶到選中的視窗，反白跟著走，所見即所得。這些綁定只在選擇器開啟時存在，不會跟你自己的設定衝突。

螢幕錄影（Screen recording）

Alt + Print Screen 會開啟 Trigger > Capture > Screenrecord，先問你要什麼音軌：無音訊、桌面音、桌面加麥克風、桌面加麥克風加 webcam。最後一項只在你真的接了相機時出現。選完後得到跟截圖一樣的選擇器：拖曳區域，或點視窗、點螢幕。

錄影跑在 gpu-screen-recorder 上，以 60fps 在顯示卡（Graphics Processing Unit，簡稱 GPU）上編碼，非不得已才退回中央處理器（Central Processing Unit，簡稱 CPU）。成品是 ~/Videos 下的 MP4，命名如 screenrecording-2026-08-13_14-22-05.mp4。用 OMARCHY_SCREENRECORD_DIR 可改位置，但注意：跟截圖目錄不同，這個目錄必須事先存在，否則錄影拒絕啟動。

錄影時頂欄會出現小指示燈，點它即停止。也可再按一次 Alt + Print Screen 停止，或到 Trigger > Capture > Screenrecord 下的 Stop Screenrecording（只在錄影中出現）停止。

停止前會做一點整理：剪掉第一幀，有音訊則正規化到 -14 LUFS，並把開頭 PipeWire 擷取的爆音靜音。接著通知帶著錄影縮圖彈出，點它即以 mpv 播放。

Webcam 子母畫面（The webcam overlay）

用 webcam 錄影時，相機會以釘住的裁切直式小窗出現在錄影畫面的右下角。若擋住需要的東西，可即時調整大小：

快捷鍵功能
Super + Alt + [webcam 子母畫面縮小
Super + Alt + ]webcam 子母畫面放大

共三段：小、中、大，快捷鍵逐段切換，預設為中。三段與錄影成比例，不論錄 1080p 螢幕或 6K 螢幕，相機佔畫面比例相同。若錄的是區域而非整台螢幕，子母畫面會錨定在該區域角落而非螢幕角落，保證留在鏡頭內。

也可用 omarchy-capture-webcam-resize small 直接指定，或 reset 回到中。

文字、二維碼與顏色（Text, QR codes, and colours）

Super + Ctrl + Print Screen 框選區域並以光學字元辨識（OCR）送到剪貼簿，詳見文字擷取與聽寫。

Trigger > Capture > QR Code 對二維碼（QR code）做同樣的事。框選含碼區域，解碼值即送剪貼簿。它只找 QR code——濃密的螢幕內容很容易被誤判成條碼。注意：解碼值只去剪貼簿，不印出、不進通知，並標記為敏感，不留在剪貼簿歷史。二維碼常帶機密——例如雙重驗證（Two-Factor Authentication，簡稱 2FA）設定的 otpauth:// 網址——你不會想讓它留在紀錄裡，貼上照常可用。

Super + Print Screen（或 Trigger > Capture > Color）把游標變成滴管，點螢幕任意處，顏色即上剪貼簿。再按一次快捷鍵可不取色退出。

分享前的轉檔（Transcoding before you share）

4K 螢幕錄影或手機直出的 HEIC 常常太大，無法直接傳送。Super + Ctrl + .（或 Trigger > Transcode）可解。它會在 ~/Pictures 與 ~/Videos 上開模糊檔案選擇器，再問你要的格式與尺寸。

圖片轉 jpg 或 png，分高、中、低三檔，寬度上限分別為 3160、2160、1080 像素。影片轉 mp4 或動態 gif，分 4k、1080p、720p 三檔。轉好的檔寫在原檔隔壁，檔名帶解析度，如 demo-1080p.mp4，路徑以檔案網址（file URI）形式複製到剪貼簿，可直接貼進支援檔案拖放的應用。

終端機也行，若你早知道要什麼：omarchy transcode ~/Videos/demo.mov mp4 1080p。另有 omarchy transcode ascii 把圖片轉 ASCII 藝術——那招多半是拿來做品牌的。

傳到別處（Sending it somewhere）

檔到手後，Super + Ctrl + S 開啟分享（Share）選單，透過 LocalSend 送到同網域的其他裝置，詳見圖形應用（GUIs）。
