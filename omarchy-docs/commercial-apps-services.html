商業應用與服務

Omarchy 主要提供免費開源軟體，但並不教條。有時候最佳解是商業產品，那就坦然使用。以下是提供簡易安裝的部分選項。

1Password

把密碼放在密碼管理員是最佳實踐，跟團隊共事時更是如此。1Password 是很棒的解法，還附命令列工具，方便在腳本中查金鑰。

以 Super + Shift + / 啟動 1Password。若尚未安裝，該快捷鍵會先啟動安裝（也可用 Omarchy 選單的 Install > Service > 1Password）。安裝程式也會一併裝好 Chromium 用的 1Password 擴充功能。

Bitwarden

Bitwarden 是密碼管理員領域的開源替代品，免費方案已涵蓋多數個人用途。以 Omarchy 選單的 Install > Service > Bitwarden 安裝，會一併帶來 Bitwarden 命令列工具。

Spotify

Spotify 是全球最受歡迎的串流音樂服務。Linux 版應用程式功能齊全，包含離線播放。

以 Super + Shift + M 啟動 Spotify。跟 1Password 一樣，若尚未安裝，快捷鍵會先啟動安裝（或使用 Omarchy 選單的 Install > Service > Spotify）。

Dropbox

Dropbox 是在機器之間同步檔案、同時在雲端留備份的好方法。到 Omarchy 選單選 Install > Service > Dropbox 設定。跑起來之後，把滑鼠移到頂欄右側的托盤，對 Dropbox 圖示按右鍵完成設定。

Tailscale

Tailscale 是網狀 VPN，讓你透過網際網路安全存取所有電腦與伺服器變得超簡單。到 Omarchy 選單選 Install > Service > Tailscale 設定。

它會在頂欄取得一個面板、一個管理主控台網頁應用程式，以及用來在機器間傳檔的 Taildrop，請見 networking。

ONCE

ONCE 是 37signals 推出的買斷制軟體，在自己的伺服器上跑，例如 Campfire 聊天系統。到 Omarchy 選單選 Install > Service > ONCE 安裝，會啟用背景服務並把你丟進 ONCE 終端機介面繼續後續設定。

NordVPN

NordVPN 是標準 VPN 服務，可讓你的流量從全球多數地區出口。到 Omarchy 選單選 Install > Service > NordVPN 設定。在它要求的重開機之後，執行 nordvpn login 驗證。
