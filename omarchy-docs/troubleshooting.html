疑難排解

我用更新把系統搞壞了！

先嘗試 rollback 到最近一次更新之前的版本。若無效，使用 omarchy-debug 把問題分享到 Discord 的 #omarchy-help 頻道。若還是不行，可用 omarchy-reinstall 重新安裝預設設定與套件。

為什麼有些 App 在螢幕上顯得很大？

Omarchy 預設為 2x 高解析度螢幕，需要在 ~/.config/hypr/monitors.lua 將 GDK_SCALE 設為 2。若你用的是 1x 螢幕，可把 local omarchy_gdk_scale = 2 改為 1（再重新啟動過大的 App）。詳見手冊 monitors 一節。

Spotify 可用 Ctrl + Minus 縮小介面（Ctrl + Plus 放大）。

為什麼 Caps Lock 沒反應？

在 Omarchy 中，Caps Lock 被指定為 xcompose key，用來快速輸入 emoji 與其他自動補全。若真的懷念 Caps Lock，可編輯 ~/.config/hypr/input.lua 把 xcompose key 改為其他鍵，例如右 Alt：

hl.config({ input = { kb_options = "compose:ralt", }, })

Wi-Fi、藍牙、音訊或觸控板突然罷工

重開機前，先試著單獨重啟出問題的子系統。Omarchy 選單的 Update > Hardware 內有 Wi-Fi、Bluetooth、Audio 與 Trackpad，重載其中一項即可解決多數「五分鐘前還好好的」狀況，例如連不回去的藍牙耳機、休眠後沒反應的觸控板、拔掉螢幕後消失的聲音。

為什麼外接喇叭沒聲音？

多半是因為沒設為主要輸出。點選頂欄右側的喇叭圖示，會開啟音量彈窗，可選擇輸出裝置（也可混音各 App 音量）。

筆電喇叭聽起來怪怪的

部分筆電上，Omarchy 會自動套用喇叭調校，修正內建喇叭的頻率響應。omarchy audio tuning status 可查詢你的機器是否有啟用，omarchy audio tuning off 可關閉，改聽喇叭原始聲音。

為什麼登入或 sudo 時密碼過不了？

多半是輸錯太多次被鎖定了。若卡在鎖定畫面，可按 CTRL + ALT + F2 開新 TTY，以 root 登入後執行 faillock --reset --user [your-username]，即可解除鎖定。

為什麼 1Password SSH Agent / CLI 的授權提示沒跳出來？

有 2 個可能原因：

要讓豐富的核准提示出現，Settings > Advanced > Use Hardware Acceleration 必須開啟。注意：需重開機才會生效。或開機後尚未啟動過 1Password，提示就不會出現。
