網路設定

網路（Networking）在 Omarchy 中由網路管理員（NetworkManager）處理，你可以從頂欄（top bar）的網路圖示操作，或使用 Super ＋ Ctrl ＋ W 開啟面板。

該面板會掃描 Wi-Fi 網路、顯示訊號強度並連線。有線網路（Ethernet）什麼都不用做——插上就能用。如果你偏好待在終端機，nmtui 提供相同控制，另外還有一組 omarchy network 指令可用。

分享你的 Wi-Fi

與其大聲唸出冗長密碼，不如在連上 Wi-Fi 時執行 Setup > Network > QR Code。螢幕上會出現 QR Code，任何手機相機掃描即可加入。用過一次之後，你會發現它的使用頻率高得超乎預期。

如果你確實需要密碼本身，執行 omarchy network password <interface> 即可印出。

DNS

Omarchy 使用網路經 DHCP 配發的 DNS。你可以在 Setup > Network > DNS 覆寫整台機器的設定，其中 Cloudflare 與 Google 都是一鍵選項。選擇 Custom 可自行輸入伺服器。

終端機操作：omarchy dns 印出目前供應商，omarchy dns Cloudflare 則切換為該供應商。

鎖定 Wi-Fi 頻段

如果你的路由器把 2.4GHz、5GHz、6GHz 放在同一個網路名稱下，筆電有時會黏在慢速頻段上。omarchy network band 顯示目前頻段，omarchy network band 5 鎖定至 5GHz，用 auto 恢復自動選擇。

這裡鎖的是頻段而非特定基地台（access point），因此你仍可在基地台之間正常漫遊。

速度有多快？

Trigger > Speed Test > Network Speed Test 以一對儀表測量實際上下行速度。終端機指令為 omarchy network speedtest down 或 up。（選單旁邊還有磁碟測速，如果你要抓的是另一個瓶頸。）

防火牆

防火牆預設開啟，阻擋所有連入流量，唯一例外是連接埠 53317，讓 LocalSend 開箱即用。

SSH 預設關閉，以 Setup > Security > SSHD 開啟，該動作會啟動服務、開啟連接埠 22（具備防暴力破解的速率限制）並授權金鑰。Docker 同樣被鎖定，容器不會意外暴露到外部。完整說明見 security 章節。

Tailscale

Tailscale 是一種網狀 VPN（mesh VPN），讓你透過網際網路存取所有電腦與伺服器，簡單又安全。以 Install > Service > Tailscale 安裝。

安裝後頂欄會出現 Tailscale 面板，可連線／斷開 tailnet、切換帳號、選擇出口節點（exit node）——自己的機器與 Mullvad 區域都會出現在清單中。它也能瀏覽你的機器，Taildrop 就在這裡：選一台機器按 s 傳檔，或按 c、n、d 複製其 IP、名稱或完整 DNS 名稱。終端機等效指令為 omarchy tailscale send <machine> [file...]，傳給你的檔案會自動落在 ~/Downloads。送達通知會一直等到你點開或關閉，因此即使你人不在機器前，回來時檔案通知還在等你回應。

安裝同時會加入一個 Tailscale 管理主控台（admin console）的網頁應用程式（web app）。

當它壞掉時

重開機之前，先試著單獨重啟出問題的部件。Update > Hardware 內有 Wi-Fi、藍牙（Bluetooth）、音訊（Audio）與觸控板（Trackpad），重新載入其中之一就能解決多數「五分鐘前還好好的」狀況。另見 troubleshooting 章節。
