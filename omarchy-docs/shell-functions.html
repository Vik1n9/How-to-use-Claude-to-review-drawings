終端函數

Omarchy 內建一組 shell 函數，用來簡化日常任務，把參數繁瑣的呼叫包裝起來。

壓縮 Compression

compress [file/dir]：把檔案或目錄打包成 tar.gz。

decompress [file.tar.gz]：解開 tar.gz 檔案。

磁碟 Drives

iso2sd [image.iso]：以互動式挑選磁碟，把指定的 iso 檔寫成 SD 卡開機碟。

format-drive [device] [name]：把整顆磁碟格式化為單一 exFAT 分割區（Windows 與 macOS 皆可讀寫）。不帶參數執行可查看可用磁碟。請小心使用！

開發版面 Dev layouts

為 tmux 準備的瞬間多窗格開發版面：

tdl [ai]：建立 Tmux Dev Layout，包含編輯器、AI 助理與終端機。使用助理別名，例如 tdl c 代表 opencode，tdl cx 代表 Claude Code，也可以傳入兩個助理同時執行，例如 tdl c cx。

tds：建立 Tmux Dev Square，包含編輯器、diff 監看（透過 hunk diff --watch）、終端機與 opencode。

tdlm [ai]：為目前目錄下的每個子目錄各開一個 tdl 視窗。

tsl [count] [command]：以網格平鋪開啟一群窗格，全部執行相同指令（適合用來指揮 AI 助理大軍）。

同樣的版面在 Herdr 中也有對應版本：hdl、hds、hdlm 與 hsl。

Git 工作樹 Git worktrees

ga [branch]：在目前倉庫旁邊新建 worktree 與分支，並跳進去。

gd：刪除目前所在的 worktree 與其分支（會先要求確認）。

Rsync 監看 Rsync watchers

rsw [source] [destination]：啟動背景監看，任何檔案變動就把 source 同步到 destination。destination 可以是遠端主機，例如 rsw ~/Work/app nyc-dev:Work/app。

lsw：列出所有作用中的監看。

dsw：停止所有監看。

SSH 連接埠轉發 SSH Portforwarding

適合在本機開發、同時享有遠端主機 localhost 安全上下文權限的情境。

fip：透過 SSH 把遠端主機的一個或多個連接埠轉發到本機。

dip：中斷一個或多個已轉發的連接埠。

lip：列出所有作用中的 SSH 連接埠轉發。

例如你在 nyc-dev 這台機器上的 3000 埠起了開發伺服器，執行 fip nyc-dev 3000 即可轉發，讓 localhost:3000 實際連到 nyc-dev:3000，而且不需要 SSL 憑證就能建立測試 WebSocket 所需的安全上下文。

SSH 斷線重連 SSH reconnection

ssh 本身被包裝成函數：當遠端 tmux、Herdr 或編輯器佔住終端機而連線中斷時，它會清理終端機狀態；互動式連線斷掉後會自動重連（按下 Ctrl-C 可停止重試迴圈）。
