品牌識別

品牌識別（Branding）：Omarchy 允許你為開機解鎖、螢幕保護程式與關於畫面設定公司標誌或個人圖像。

開機解鎖

以 omarchy plymouth preview 預覽自訂標誌與配色效果。它接受背景色、文字色、標誌 png 與預覽圖路徑：

omarchy plymouth preview '#1d2021' '#ebdbb2' logo.png preview.png

再以 omarchy plymouth set 套用設定：

omarchy plymouth set '#1d2021' '#ebdbb2' logo.png

該指令同時會讓 SDDM 登入畫面套用相同配色與標誌。若想還原，以 omarchy plymouth reset 處理。

螢幕保護程式

螢幕保護程式的標誌可在 Style > Screensaver 下更換。它是 ASCII 標誌，因此可以直接編輯文字，也可以丟給它 png 或 svg 圖檔，由我們轉成 ASCII。效果相當酷。

該選單有三個項目：

Edit Text 在編輯器中開啟 ~/.config/omarchy/branding/screensaver.txt。輸入或貼上任何想寫的——ASCII 藝術、你的名字、一句粗話。存檔退出後螢幕保護程式會立刻啟動，讓你直接看到成果。

Set From Image 開啟 png 或 svg 的檔案選擇器，轉成 ASCII 後顯示結果。輪廓清晰的標誌效果遠勝照片。

Restore Default 恢復 Omarchy 標誌。

關於畫面

Style > About 下有同樣的三個選項，對應 Omarchy 選單叫出的 About 畫面，用法完全相同——檔案是 ~/.config/omarchy/branding/about.txt，每次修改後 About 視窗都會彈出。About 圖案轉換尺寸小於螢幕保護程式，因為它要塞進視窗而非填滿螢幕。

視窗開啟時，一道綠色微光每隔幾秒掠過圖案再靜止。你的自訂圖案同樣享有該動畫，只要其中每個字元都是一個欄寬——Set From Image 產出的皆符合。以 emoji 或雙倍寬字元拼的圖案則保持靜止；若你自備 fastfetch 設定，標誌同樣靜止。這些情況下的靜止是動畫主動讓路而非故障，因為微光滑過它們會讓該行其餘部分錯位。

自己轉圖

兩個 Set From Image 背後呼叫的都是 omarchy transcode ascii，若想掌控轉換可直接執行：

omarchy transcode ascii ~/logo.svg ~/.config/omarchy/branding/screensaver.txt --width 100

它接受 --width 與 --height（終端機欄列數）、--mode（braille 為預設且精細得多，或 block）、--threshold 百分比（判定哪些像素算標誌本體）、--invert（標誌淺色襯深色底時用）。若轉出來是一團糊，threshold 通常是要轉的那顆旋鈕。

用文字代替標誌

omarchy ascii 以 Delta Corps Priest 1（Omarchy 字標本身所用的 FIGlet 字型）繪製文字，讓螢幕保護程式顯示一句話而非圖案：

omarchy ascii "Back in five" > ~/.config/omarchy/branding/screensaver.txt

它以參數接受文字，未給參數時從管線（pipe）讀取。該字型只帶字母與空格——繪製時沒有數字與標點——因此其他字元會被丟棄並在 stderr 具名提醒，而非靜默吞掉。
