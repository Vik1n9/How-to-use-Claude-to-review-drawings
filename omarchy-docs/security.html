安全性

Omarchy 極度重視安全。這是一套能拿來做 Real Work in the Real World 的作業系統，弄丟筆電也不該演變成安全事故。我們的做法如下：

Full-disk encryption is mandatory：保護實體資料最重要的步驟。若電腦遺失或被竊，資料以標準 LUKS（Linux Unified Key Setup）完整加密。

Firewall is enabled by default：預設阻擋所有傳入流量，僅 LocalSend 的 port 53317 除外。連 ssh 預設也是關的，需經 Setup > Security > SSHD 開啟，設定會開啟 port 22（具 brute force rate limiting）。我們甚至用 ufw-docker setup 鎖住 Docker 存取，避免容器意外暴露於外界。

Arch always have the latest updates：Omarchy 底層的 Arch 是 rolling distribution，任何套件的安全漏洞一旦修補，即可透過 omarchy-update 取得。你永遠跑在最新、最安全的版本上。

Omarchy maintains its own packages and mirror：Omarchy 預設僅依賴 Arch 自家 core/extra/multilib repositories 與 Omarchy Package Repository。可從 AUR 直接安裝軟體，但基礎安裝不含，僅少數選用安裝（如第三方瀏覽器）會從 AUR 拉取。

Cloudflare protects us from DDoS：所有 Omarchy 發布基礎設施，含 ISOs、Omarchy packages、Arch mirror，皆受 Cloudflare 的 DDoS shield 與 CDN 保護，可用性極佳。

變更密碼

加密安裝有兩組密碼：開機解鎖磁碟者，以及登入與 sudo 者。兩者皆可在 Omarchy 選單的 Update > Password 下變更，Drive Encryption 管前者，User 管後者。變更磁碟密碼會先要求輸入舊密碼，請備妥。

移交已用過的機器

若要把機器交給他人，無需重裝。在 Omarchy 選單執行 Setup > Reset Computer，輸入 reset 確認後重開機。該動作清除所有使用者帳號與 /home 內一切，丟掉安裝後所做的套件與系統變更，並清除機器識別：網路連線、host keys 等。重開後回到首次開機的設定精靈，新主人可輸入自己的名稱、密碼與加密密碼。

其原理是還原安裝程式建立的 baseline snapshot，故僅適用於由 Omarchy ISO 安裝的機器。未加密磁碟上的 reset 只是刪除而非安全抹除，若資料敏感請改用全新安裝。

Passwordless sudo

有時你會想讓 sudo 別再詢問，最常見的是 AI agent 要長時間做系統工作時。Setup > Security > Passwordless Sudo 可關閉詢問 15 分鐘，時間到自動恢復。提前結束可在時限內再執行一次，或用 omarchy-sudo-passwordless 30 自訂分鐘數。

請清醒看待此選項：開啟期間，以你的使用者身分跑的任何東西都能免詢問取得 root。這正是目的，也是全部風險。

Signing Keys

所有 ISO signatures 與 Omarchy repo package 的公鑰為 40DFB630FF42BCFFB047046CF0134EE680CAC571（至 openpgp.org 驗證）。omarchy/omarchy-keyring 套件亦內含此金鑰，後續更新會自動沿用。

任何 ISO release 的簽名檔即 URL 加 .sig，例如 https://iso.omarchy.org/omarchy-x.x.x.iso.sig。
